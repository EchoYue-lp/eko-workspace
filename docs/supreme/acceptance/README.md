## 三、启动方式（只此一种）

在 Finder 双击：

```
.echo-semantic/local/repair-App-warm-continuation-20261103-r01/epoch-01/启动修复版.command
```

- 它会把应用指向隔离测试数据（含 `ubuntu-ssh-test-20261102` 工作空间）；
- 若检测到已有 Eclip 在运行，它只提示退出并停止，不会替你退出；
- **直接双击 `Eclip.app` 会读默认 `~/.eko`，那是 8–9 月的旧数据**，看不到测试工作空间。

## 七、几条能省时间的提醒

1. **重开后内容偏少不是丢失**：历史按每批 4096 条事件追平，等 2–3 秒或切换会话再看。
2. **找不到「推理深度」不是缺陷**：模型表单只有 `Max tokens`、`Context window` 两项。
3. **远端 `git` 报错可能正确**：终端行为多数由系统 ssh 与远端主机决定，判断标准是「是否真实反映远端」。
4. **ubuntu 终端可能留着上次没回车的命令**：进去先 `Ctrl+C` 清行再输入。
5. **中英混排的报错不是缺陷**：重复目录会显示 `Directory already contains a workspace: …`。
