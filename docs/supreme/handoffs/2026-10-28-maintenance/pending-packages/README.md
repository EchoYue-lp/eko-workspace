# 暂停切点的未合流工程包

这些压缩包只保存已冻结候选、原始补丁、base/after SHA、Review及必要恢复材料，**不是生产采用**。每个json记录源目录、成员、SHA、实际解压回读和资格边界；当前包索引集中列出各包。产品当前源码已分别WIP提交，正式文档与API仍以所属子仓为准。

包内保留历史路径/状态是来源记录，不代表当前目录仍存在或产品已经完成。跨会话原基底存在与最终EKO不同的文件，因此同时保存原base；不得覆盖现源码。用户数据、授权、真实消息、构建target和大型二进制没有复制进这些Git工程包。恢复时先核验archive_sha256，再在独立空目录解压并按成员SHA核验；不得自动运行包内脚本或把patch套入有未保存改动的工作区。
