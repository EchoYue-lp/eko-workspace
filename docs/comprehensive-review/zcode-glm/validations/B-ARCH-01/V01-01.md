## Claim

The eight `echo-agent` workspace members form a coherent acyclic dependency
graph in which sub-crates never depend on the root `echo_agent` facade and
never reverse the documented layering (`core`/`macros` → mid-layer crates →
`execution` → root facade). Resolver and workspace metadata are consistent.

## Method

Read every workspace `Cargo.toml` in full and extract `[workspace]`,
`[package]`, `[features]`, and `[dependencies]` sections. Then check
non-doc references (skipping `///`, `//!`, and `//` lines) to `echo_agent`
inside sub-crate `*.rs` files to detect any source-level reverse dependency
that bypasses Cargo.

Procedure:

1. `cat` each of the 8 manifests and record every path dependency and
   feature-fwd declaration.
2. `grep -rn "echo_agent" --include="Cargo.toml"` across the workspace to
   confirm no sub-crate Cargo.toml names the root crate.
3. `grep -rn "use echo_agent" --include="*.rs"` in sub-crate `src/` trees,
   filtering out doc comments, to confirm no static reverse imports.
4. `grep -rn "extern crate" --include="*.rs"` to detect manual bypasses.
