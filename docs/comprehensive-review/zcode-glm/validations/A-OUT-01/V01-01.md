## Deviations

The inspection was static; no executable test was run to construct a
conversation with tool calls and export it. The content-completeness
conclusion (d) is reached by reading the builder's source, which is
deterministic — the builder does not branch on `tool_calls_json` or
`tool_result_json`, so the fields are provably dropped regardless of input.

## Conclusion

The format/renderer registry is incoherent: one enum is dead with a stale
flag promise (P2-01), one is live (ReviewExportFormat), one carries a dead
variant plus a parallel dead exporter (P2-02), the conversation Markdown
export is lossy (P2-03), and the wire-string parser is duplicated (P3-01).
The live research-export registry itself is correct and complete (all
seven formats honored by `export_review`, conditional DOCX/PDF per
availability); the failures are around it, not in it. Supports findings
A-OUT-01-P2-01, A-OUT-01-P2-02, A-OUT-01-P2-03, A-OUT-01-P3-01.
