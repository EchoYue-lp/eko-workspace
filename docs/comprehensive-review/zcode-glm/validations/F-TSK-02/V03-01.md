## Claim

The topological / ready-frontier order produced by
`task_topological_order` is deterministic for a fixed input task set: given
the same `&[TaskSpec]`, every call returns the same order, with no
dependence on HashMap iteration order, pointer identity, or call timing.
The ready frontier for the runtime scheduler is therefore reproducible.

- Tie-breaking among ready tasks of equal in-degree is stable (sorted id or
  insertion order), not HashMap iteration order.
- Repeated calls on the same input return the same output.
