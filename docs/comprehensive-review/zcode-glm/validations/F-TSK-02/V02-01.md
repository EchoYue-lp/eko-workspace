## Claim

`PlanValidator::validate()` performs the three structural integrity checks
required of a task DAG: cycle detection (via `task_dependency_cycles`),
missing-node detection (an edge targeting a task id absent from the spec
set), and self-dependency detection (a task depending on itself). The
result is a structured `ValidationReport`, not a runtime state transition.
