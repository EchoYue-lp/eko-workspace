## Claim

Features defined as `= []` (no dependencies) in `echo-agent/Cargo.toml`
either (a) gate real code via `#[cfg(feature = "...")]` and are therefore
live markers, or (b) gate nothing and are dead. Dead features should be
removed per `AGENTS.md` "代码清理:无需兼容,过时代码可直接删".

## Method

Read-only classification. Working directory:
`/Users/ls/MyWork/code/ylp_agent_learn/lp-agent/echo-agent`.

```text
1. Extract all features defined as `= []` from root Cargo.toml [features].
2. For each, grep -rn 'cfg(feature = "<name>")' and 'feature = "<name>"'
   across all .rs files in the workspace.
3. Classify: cfg matches > 0  -> marker feature (gates real code)
             cfg matches = 0  -> DEAD feature
4. For DEAD features, also grep for the bare name in comments and re-exports
   to confirm zero code references.
```

Each `= []` feature resolves unambiguously to either a live module gate or
a dead declaration. Dead features should be a small, deletable set.
