## Conclusion

Documentation is internally inconsistent with the code. The capability is
silent in the README and examples (correct given it is dead), but the
module doc and the `enable_notebook` builder doc both promise live
Jupyter-like behaviour that the runtime does not perform. The historical
AUDIT_REPORT.md RwLock-poison finding is resolved (positive drift). Net:
the "coherent, reachable framework API" framing fails the documentation
contract too — a consumer who reads the builder doc and calls
`.enable_notebook(true)` gets a silent no-op. Supports task findings
F-NBK-01-P1-01, F-NBK-01-P2-01, and the V04 historical-claim row for
`AUDIT_REPORT.md`.
