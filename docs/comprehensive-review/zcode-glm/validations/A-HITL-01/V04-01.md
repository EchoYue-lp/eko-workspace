## Claim

The four user-selectable permission modes (`default`, `auto-edit`,
`full-auto`, `strict`) map deterministically to the framework's
`PermissionMode` variants and produce the expected tool-approval
behaviour on the agent-automation path. `full-auto` auto-allows every
agent tool call except protected paths (`.git/.ssh/.env/.aws/...`);
`default` requires approval for Write / Execute / Network /
Sensitive and auto-allows Read. No direct-user command requires
`full-auto`. The provider-implementation tests for the application's
HITL module pass cleanly.
