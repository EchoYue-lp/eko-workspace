## Claim

Analysis results are traceable to their source data via per-run SHA-256
fingerprints of the script, inputs, parameters, and seed, plus the captured
environment and sandbox type. Research sources are traceable to their origin
via a `provenance` vector (provider, query, retrieved_at, record_url), and
evidence records are linked to sources and reviews that `audit_review`
cross-checks for dangling references.

## Expected Result

- `AnalysisRunRecord` captures: script SHA-256, per-input SHA-256 with
  availability flag, parameters SHA-256, random seed, environment map,
  sandbox_type, exit_code, output (bounded), output_truncated flag.
- Stale detection reports a specific reason for each divergence (script /
  input list / individual input / parameters / seed).
- `SourceRecord.provenance` is populated by every ingestion entry point
  (search_and_ingest, ingest_tool_output, import_zotero, create_source).
- `upsert_evidence` rejects orphan source_id or review_id.
- `audit_review` emits error/warning issues for: missing source,
  orphan evidence, evidence-outside-review, empty claim, missing locator,
  included-without-evidence, exclusion-without-reason.
- Analysis tests confirm stale detection after a parameter change and after
  an input file content change.
