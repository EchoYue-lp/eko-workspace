## Claim

EKO enforces a clear boundary between exploratory (descriptive) and formal
(inferential) analysis: (a) the framework provides only an
`ExploratoryStatisticsTool` that returns descriptive summaries with
`inference=false`, and (b) formal inference is routed through reviewable
Python/R scripts executed via the framework `run_code` tool under
`analysis/<id>/`, with the boundary asserted by the subagent prompt, the
domain profile, and the tool routing layer — not by a runtime state machine.
