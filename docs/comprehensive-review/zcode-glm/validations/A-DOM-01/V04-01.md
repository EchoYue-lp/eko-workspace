## Claim

Analysis artifacts are preserved per-run as content-addressed files (with
SHA-256, size, kind) under `analysis/<id>/outputs/`, cleared before each run
so a failed run cannot inherit previous outputs. The paper workbench
(`export_review`/`export_all_review_formats`) renders the review to seven
formats (Markdown, JSON, CSV, BibTeX, RIS, plus PDF/DOCX when a renderer is
available) with the citation audit embedded in each artifact. Two rendering
defects exist — silent source drop in `export_review` and BibTeX key/escape
weakness — see findings A-DOM-01-P3-02 and A-DOM-01-P3-03.

## Expected Result

- `clear_generated_outputs` wipes `environment.json`, `result.json`, and
  `outputs/` before every run, then re-creates `outputs/`.
- `collect_outputs` produces one `AnalysisOutputArtifact` per file under
  `outputs/` plus `environment.json`/`result.json`, capped at 200 files,
  skipping symlinks, with SHA-256 and extension-classified kind.
- A failed run leaves the latest run record with `outputs: []` and
  `environment: {}` (does not inherit the previous successful run's
  outputs).
- `export_review` writes the rendered bytes atomically to
  `research/reviews/<id>/reports/systematic-review.<ext>` and returns a
  `ReviewExportArtifact` carrying path, byte size, and the citation audit.
- `export_all_review_formats` always includes Markdown/JSON/CSV/BibTeX/RIS;
  PDF/Docx are added only when a renderer is available.
- Markdown table cells escape `|`; CSV cells RFC-4180-quote; BibTeX keys
  are stable; BibTeX field values do not break on `{`/`}`/`\`.

## Deviations

Two deviations from "rendered artifact is correct in isolation" — both
filed as findings, not validation failures:

1. Missing sources are silently omitted from the rendered body while the
   audit flags them. A reader of the export sees N-1 rows where the audit
   promises N. Filed as A-DOM-01-P3-02.
2. BibTeX export produces duplicate keys for same-author same-year sources
   and does not escape `{`/`}`/`\` in field values, producing invalid
   `.bib` files for common inputs. Filed as A-DOM-01-P3-03.

Neither deviation affects the Markdown/JSON/CSV/RIS formats' structural
correctness (CSV cell-quoting and Markdown pipe-escaping are sound), and
neither causes a panic or write failure. The existing
`citation_audit_and_all_report_formats_are_file_backed` test
(`research.rs:2110-2177`) only asserts files are created and the audit
has zero errors on a clean fixture — it does not exercise
duplicate-key or special-character edge cases.
