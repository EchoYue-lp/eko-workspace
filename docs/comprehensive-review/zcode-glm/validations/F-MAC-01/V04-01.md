invisible during development. A `trybuild` test suite would have caught

compile-fail cases — which are critical for proc-macro quality — are
entirely absent. Adding `trybuild` with compile-fail fixtures for
generics, missing attributes, and crate-path edge cases would materially
improve macro reliability.
