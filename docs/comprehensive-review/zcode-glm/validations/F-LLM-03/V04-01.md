## Deviations

- The Anthropic-adapter test suite has ZERO streaming tests and ZERO
  HTTP-mock tests. The streaming tool-index desync (F-LLM-03-P1-01),
  the missing streaming `anthropic-beta` header (F-LLM-03-P2-03), the
  thinking-block parse failure (F-LLM-03-P2-02), and the silent
  thinking-delta drop (F-LLM-03-P2-01) all evaded the test suite for
  this reason. This is the single largest coverage gap in the
  F-LLM-03 scope.
- The `convert_response` non-streaming path has no direct unit test.
  Its correctness is inferred from the streaming path's structurally
  similar code and from the F-LLM-01 contract tests, not exercised
  directly.
- The `build_anthropic_thinking` adapter translator has no unit test
  at the adapter level; the underlying `ThinkingConfig` translators
  are well tested in `echo-core`, but the protocol-keyed dispatch
  inside `build_anthropic_thinking` is not.

## Conclusion

The Anthropic-area test suite is well-targeted at the
`AnthropicCachePlan` strategy and `convert_request`'s cache-control
placement — the parts that were added or refactored recently. It is
notably absent on the streaming event loop, the response mappers, and
HTTP-level fidelity. The crate compiles clean and all 62 provider
tests pass. The coverage gaps are the root cause of the F-LLM-03
findings slipping through: F-LLM-03-P1-01 (streaming tool desync),
P2-01 (thinking not surfaced), P2-02 (parse failure on unknown
block), P2-03 (streaming beta header), P3-03 (error mislabeling)
would all be caught by a streaming fixture test or an HTTP-mock test
that does not exist today. Supports V01, V02, V03. Used by all
F-LLM-03 findings via the "no covering test" observation.

## Follow-Up

A future **observability / test infrastructure** task should add (a)
an HTTP-mock test that exercises `AnthropicClient::chat` and
`AnthropicClient::chat_stream` against a wiremock-recorded Anthropic
response, (b) a streaming fixture test that covers
`[text, tool_use]`, `[tool_use_A, text, tool_use_B]`, and
`[thinking, text, tool_use]` block orderings, and (c) a
`convert_response` unit test covering Text, ToolUse, mixed, and
unknown-block-type responses. Until these exist, the F-LLM-03 fixes
should land together with their covering tests.
