### Automatic mutation paths (3)

1. **Daily Dreaming pass** (`infra.rs:1143-1200`, spawned at
   `repl.rs:106`, `tui/mod.rs:1999`, `tauri/desktop.rs:247`).
   Calls `Dreaming::run` which calls `MemoryLayerManager::
   consider_promotion` → `promote_warm_to_hot` (writes MEMORY.md),
   demote, and revive. Mutates only existing memories; introduces no
   new facts. Cadence: 60s initial + 86400s interval, cancelled on
   session exit.
2. **React-engine trigger detection** (framework, `context.rs:34-137`).
   Runs per-turn. In EKO the `MemoryTriggerSink` returns `Captured`
   (`review_integration.rs:319`) and routes the trigger to the
   Evidence Inbox; **no durable write** in EKO. (The framework default
   with no sink would auto-write — not EKO's posture.)
3. **React-engine pre-compaction flush** (framework, `context.rs:676-
   798`). Runs when `ContextManager::should_compress()` returns true.
   Makes a bounded LLM extraction call and writes each extracted fact
   via `MemoryLayerManager::write_memory` directly. **NOT sink-
   interceptable** — this is the inherited F-EVO-01-P2-01, recorded
   here as A-EVO-01-P2-02. Runs in EKO because EKO installs a layer
   manager on every primary and pool agent.
