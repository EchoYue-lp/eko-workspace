## Claim

Per AGENTS.md "统一术语:只有 Subagent,没有 Worker" (Subagent-only
terminology, no Worker), the F-INT-02 scope contains **zero**
introductions of `Worker` / `worker` terminology in types, traits,
struct fields, functions, modules, variables, tool parameters,
events, logs, comments, or documentation. External fixed wire names
(third-party API constants) are the only allowed exception.

```text
cd echo-agent

    echo-integration/src/lsp/ \
```

Then classify every hit as one of:

- `violation` — new worker terminology in product/runtime path.
- `test-only` — worker term in `#[cfg(test)]` modules only.
- `third-party-wire` — external fixed API/protocol name.
- `false-positive` — substring match inside an unrelated word
  (e.g. `NetworkError`).
