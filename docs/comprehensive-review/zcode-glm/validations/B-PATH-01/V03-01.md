## Claim

For each of the five declared features in `echo-agent-cli/Cargo.toml`
(`tui`, `gui`, `channels`, `telemetry`, `devtools`), the code paths and
entry points each feature enables are enumerable, and at most one feature
(`devtools`) is a "passthrough" feature with no direct
`#[cfg(feature = "devtools")]` references in source.

## Method

Static feature-gate inventory, no execution. Procedure:

1. Read `echo-agent-cli/Cargo.toml:21-37` to enumerate features and the
   optional dependencies they pull in.
2. Grepped `src/`, `src-tauri/`, and `echo-agent-app-core/src/` for
   `#[cfg(.*feature` and grouped results by feature.
3. For each feature, listed (a) entry points enabled, (b) modules enabled,
   (c) functions gated, (d) dead or passthrough gates.
4. Cross-checked against `Cargo.toml` to confirm declared feature
   dependencies.

## Expected Result

Five declared features; `tui` and `gui` are the primary binary-routing
features; `channels` adds IM mode; `telemetry` swaps logging backend;
`devtools` is a Tauri-passthrough feature.

### Cross-feature observations

1. **`gui` implies `channels`.** A GUI build always has the IM channels
   stack available (`Cargo.toml:33`). The reverse is not true.
2. **The headless import gate** at `main.rs:15-23, 34, 94` is
   `any(feature = "tui", all(feature = "channels", not(feature = "gui")))`.
   This means:
   - `--features gui` alone: import block is OFF (GUI goes through
     `run_desktop_entry` at line 76, never reaches `run_tui_or_cli_entry`).
   - `--features tui` (default): import block is ON.
   - `--features channels` (without tui/gui): import block is ON.
   - `--features tui,channels`: import block is ON (tui wins).
3. **The three main() branches are mutually exclusive**, enforced by the
   `compile_error!` at `main.rs:88-91` (`all(not(tui), not(gui),
   not(channels))`). The combinations Cargo accepts map cleanly:

| Features | Branch taken in `main()` |
|---|---|
| `tui` (default) | line 78 → `run_tui_or_cli_entry` → TUI/CLI/channels dispatch by arg |
| `gui` + `tui` | line 78 → `run_tui_or_cli_entry` (GUI binary is separate via `src-tauri`) |
| `gui` (no tui) | line 75 → `run_desktop_entry` |
| `channels` (no tui, no gui) | line 83 → `run_tui_or_cli_entry` |
| `channels` + `gui` (no tui) | line 75 → `run_desktop_entry` |
| none | compile_error |
