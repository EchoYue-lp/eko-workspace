with the GUI/Claude Code target, and every `SlashCommand` variant and
every local `AgentEvent` reducer arm has a real implementation (no
dead variants, no missing handlers). If any capability is unreachable
or any variant has no handler, it becomes a finding.

## Deviations

The "TUI is feature-complete" claim is partially falsified by the
`parallel_tasks` dead scaffold (P2-01) and the subagent-event coverage
gap (P2-02). These are themselves the findings. The structural claims
(all 57 SlashCommands handled, all 22 AgentEvent arms handled, all 17
run_tui parameters wired) hold without exception.

## Conclusion

Supports the A-SRF-01 capability-matrix conclusion. The TUI's primary
capability surface is complete and every declared variant has a real
handler — no dead slash commands, no unreachable reducer arms. Two
parity gaps are surfaced: (a) the bottom TaskStrip has no data
producer (P2-01), and (b) subagent internal lifecycle events collapse
to a counter (P2-02). One cross-surface drift (TUI permission alias
set, P3-01) is re-filed from A-SRF-02-P2-02. This is the sole evidence
for A-SRF-01-P2-01, A-SRF-01-P2-02, A-SRF-01-P3-01.
