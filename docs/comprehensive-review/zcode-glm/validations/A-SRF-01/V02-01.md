## Expected Result

- TaskRuntime: a run + its plan tasks render in the sidebar Tasks tab
  and the `/tasks` slash command, refreshed at a fixed cadence.
- Subagent: dispatches render with at minimum agent name, status, tool
  count, and terminal summary; live thinking / token deltas are
  optional but documented if absent.
- Foreground tools: every `AgentEvent::ToolCall/Progress/Output/
  Complete/Result` updates the corresponding `ToolExecutionMessage`
  and the chat widget renders status icon, command summary, output
  tail, metadata.
- HITL: every `PendingHumanLoopKind` (Approval/Input/Selection) has a
  render path and a key-handler path.
- The coverage gap (if any) is documented as a finding rather than
  silently dropped.

- Duration: not-applicable

    `app.task_runtime_view`. Called every 250ms from `run_event_loop`
    (`:574-577`).
  - The sidebar Tasks tab (`widgets/sidebar.rs:123-239`) renders the
    run id (truncated 14), status badge, goal (truncated 20), and up
    to `(area.height - 6) / 2` tasks with `task_icon(status)` +
    title (truncated 17) + agent_role.
  - `/tasks` (`events.rs:4216-4230`) forces `sidebar_visible = true,
    sidebar_tab = 2`, refreshes, and pushes
    `format_task_runtime_view(view)` + `append_subagent_summary(...)`

  - The bottom TaskStrip (`widgets/task_strip.rs`) renders only when
    `!app.parallel_tasks.is_empty()` (`:25`) — but `parallel_tasks`
    is never populated (see V01-01 step 6). The TaskStrip is
    effectively dead; the sidebar is the only live task surface.
  - **Pass with caveat** — task render is correct and live via the
    sidebar; the dead TaskStrip is A-SRF-01-P2-01.

  Step 2 — Subagent render:

    `SubagentOutcome`.

Foreground-tool / HITL paths have no deviations.

## Conclusion

Supports the A-SRF-01 task/Subagent/tool/HITL findings. Three of the
four render paths (Task, Tool, HITL) are complete and well-tested;
the Subagent path has a real coverage gap (A-SRF-01-P2-02) where
internal lifecycle events (token deltas, thinking, LLM usage, tool
completion) collapse to a counter. The TaskRuntime sidebar refresh
works correctly; the bottom TaskStrip is dead code (A-SRF-01-P2-01).
The foreground-tool render path is the most thorough, with 10
dedicated rendering tests covering UTF-8 safety, artifact fallback,
and per-tool-name detail. The HITL card covers all three
`PendingHumanLoopKind` variants with both option-selection and
free-text input modes. This is the sole evidence for A-SRF-01-P2-02
and corroborates A-SRF-01-P2-01.
