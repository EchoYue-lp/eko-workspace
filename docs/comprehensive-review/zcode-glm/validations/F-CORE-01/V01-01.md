## Deviations

- `StepType` (`mod.rs:449-462`) is the only agent-module public type without
  Serialize/Deserialize. It represents an internal parse step rather than a
  transport contract, so this is consistent, but the absence is undocumented.
- `ReactError::Io` (`error.rs:52-53`) and `ReactError::Other` (`error.rs:55`)
  are untyped catch-alls beside the typed variants. `Io` uses `#[from]` while
  every other sub-error requires explicit `From` impls (`error.rs:334-388`).
  `MemoryError` also has its own `IoError(String)` (`error.rs:64-65`)
  distinct from `ReactError::Io(std::io::Error)` — two parallel IO channels
  in one hierarchy.

## Conclusion

Inventory is complete and confirms the framework layer exposes a single,
typed, versioned set of identities/events/errors. No duplicate
public concept inside `echo-core` for these concerns, and
`echo-agent/src/error.rs:10-14` only re-exports — it does not redefine.
Supports V02 and V03; used by findings F-CORE-01-P3-01 (catch-all variants)
and F-CORE-01-P3-02 (`StepType` non-serializable is undocumented).
