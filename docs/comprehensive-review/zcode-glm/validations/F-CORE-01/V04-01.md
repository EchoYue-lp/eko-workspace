## Deviations

- `EventEnvelope` is **not** `Clone`. Some test scenarios that compare two
  envelopes by value (e.g. asserting identity round-trip) require manual
  field-by-field reads; this is consistent with the production shape (an
  envelope owns a one-shot stream slot) but worth noting.
- No executable round-trip test (`serde_json::from_str` of a serialized
  envelope back into `EventEnvelope`) exists. The
  `serializes_versioned_contract` test only inspects outgoing JSON via
  `serde_json::to_value`; the deserialization direction is covered only
  indirectly by trait derivation.

## Conclusion

The transport contract is well-typed and tested for serialization,
ordering, terminal normalization, idempotent replay, and validator
correctness in both positive and negative cases. Coverage of deserialization
is weaker (derive-only, no explicit round-trip test). Supports findings
F-CORE-01-P3-04 (no Deserialize round-trip test) and the overall
pass-status of the task.
