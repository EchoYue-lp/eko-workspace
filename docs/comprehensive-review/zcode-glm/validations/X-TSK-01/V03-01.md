## Claim

No parallel task/plan/todo CRUD exists anywhere in either repository:
no `todo_write`, no `plan_create`, no `plan_patch`, no `plan_execute`,
and no second `task_create`/`task_update`/`task_list`/`task_execute`
tool registered outside the framework service. The four canonical
task-relationship tool names (`task_create`/`task_update`/`task_list`/
`task_execute`) are the complete set; the three EKO-owned orchestration
tools (`create_complex_task`/`check_run_status`/`cancel_run`) operate
on Run lifecycle, not on the task graph. AGENTS.md rule 6 holds.

## Method

Whole-repo grep across both `echo-agent` and `echo-agent-cli` for the
forbidden CRUD names and for every `fn name(&self) -> &str` tool
definition. Searches exclude `target/`, `.worktrees/`, `.DS_Store`.

```text
# Forbidden CRUD tool names anywhere in production source:
grep -rn 'todo_write\|plan_create\|plan_patch\|plan_execute' \
  --include='*.rs' --include='*.toml' --include='*.md' \
  echo-agent echo-agent-cli \
  | grep -v '/target/' | grep -v '/.worktrees/'

# Canonical task tool names in echo-agent-cli (verify nothing beyond the 4):
grep -rn '"task_create"\|"task_update"\|"task_list"\|"task_execute"' \
  --include='*.rs' echo-agent-cli/echo-agent-app-core/src echo-agent-cli/src \
  | grep -v '/target/' | grep -v '/.worktrees/'

# Every Tool::name impl in echo-agent-cli (the full tool-name inventory):
grep -rn 'fn name(&self) -> &str' \
  --include='*.rs' echo-agent-cli/echo-agent-app-core/src echo-agent-cli/src \
  | grep -v '/target/' | grep -v '/.worktrees/'

# Cross-check the framework tool names too:
grep -rn 'fn name(&self) -> &str' \
  --include='*.rs' echo-agent/echo-orchestration/src echo-agent/src \
  | grep -v '/target/' | grep -v '/.worktrees/' | head -30

# Tool-exposure constant:
grep -rn 'TASK_TOOLS\s*:\s*&\[-' \
  --include='*.rs' echo-agent-cli \
  | grep -v '/target/' | grep -v '/.worktrees/'
```
