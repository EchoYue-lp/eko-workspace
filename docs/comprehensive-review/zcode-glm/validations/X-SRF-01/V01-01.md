### Key observations

1. **Chat and task lanes are fully unified.** Every applicable mode
   reaches `drive_chat` (chat lane) or `execute_run` /
   `drive_agent_run` (task lane). No parallel implementations.

2. **Channels is the lowest-parity attended mode.** It misses
   `/cron`, `/plugins`, `/worktrees`, `/memory*` slash commands
   (X-SRF-01-P3-01). The five wired commands (`/mode`, `/trace`,
   `/analysis`, `/papers`, `/skills`) cover the IM-relevant subset
   but not the operational one.

3. **LSP interactive management is missing everywhere.** Every mode
   has LSP *tools* (registered at `runtime.rs:582-586`) but no mode
   has a `/lsp` slash command or LSP panel (X-SRF-01-P2-05). This is
   a cross-surface gap, not a per-surface one.

4. **Subagent rendering varies materially.** GUI has full dashboard;
   TUI collapses to a counter; CLI/channels/cron/background have
   minimal or no live render (X-SRF-01-P2-04).

5. **Browser and MCP are reachable as agent integrations everywhere**
   but their interactive management surfaces are uneven (browser:
   GUI-only pane; MCP: GUI over-validates, CLI stubs, channels
   config-file only).

6. **Unattended triggers (cron, background) intentionally omit HITL,
   attachment, chat, MCP-management, plugins, memory, skills,
   worktree, analysis, research, browser-pane.** These are not gaps;
   they are the defining characteristic of "unattended".
