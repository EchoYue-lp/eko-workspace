## Claim

For each parity gap identified in V01's capability matrix, there is a
specific missing event / tool / attachment / HITL / cancel / recovery
path on a specific mode, attributable to a specific owning task report
and a specific code anchor. The gaps are surface-wiring gaps, not
architectural gaps (the framework supplies every primitive the
surfaces need).

The gap inventory must cover at minimum:

- Missing slash-command surface on channels (`/cron`, `/plugins`,
  `/worktrees`, etc.).
- Missing interactive panes (TUI terminal; TUI/GUI/CLI LSP panel).
- Missing service wiring (channels-only skips scheduler + BG).
- Missing cancel handle (REPL + channels Chat/Auto turns).
- Missing recovery path (cron runs recovered to Paused but not
  auto-resumed).
- Asymmetric persistence (GUI-only `ToolExecutionRepository`).
- Asymmetric subagent observability (TUI collapses 11/16 variants).
- Cross-surface canonicalization drift (permission-mode aliases).
- GUI MCP IPC over-validation blocking local servers.

## Method

Static cross-report synthesis at
`/Users/ls/MyWork/code/ylp_agent_learn/lp-agent`, both repos at the
pinned commits. Each gap is recorded with:

- The capability row in V01's matrix it affects.
- The mode(s) where the gap is observed.
- The owning dependency report finding.
- The exact code anchor proving the gap.
- The framework primitive that already exists but is not wired.

```text
For each candidate gap:
  1. Identify the capability (chat / task / subagent / tool / HITL /
     attachment / browser / MCP / LSP / resume / memory / skills /
     plugins / cron / worktree / analysis / research).
  2. Identify the mode where the gap is observed.
  3. Find the code anchor proving absence (grep for the command /
     pane / wiring; verify zero hits OR a stub).
  4. Find the framework primitive that already exists to fulfill the
     capability (proving it is a wiring gap, not an architectural
     one).
  5. Cite the owning dependency report's finding ID.
```
