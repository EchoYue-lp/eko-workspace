## Claim

A representative sample of 5 examples from `echo-agent/examples/` reference
the current public API: every imported type, macro, builder method, and
event variant they use resolves to a real definition in the current source
tree. (F-API-01-V03 already covered the canonical demo00/01/02/03; this
validation deliberately samples examples F-API-01 did not touch, including
the newest demo70, to detect example drift.)

## Method

For each of the 5 sampled examples, enumerate the public-API symbols it
uses and grep the current source tree for each symbol's definition or
re-export. Working directory:
`/Users/ls/MyWork/code/ylp_agent_learn/lp-agent/echo-agent`.

```text
For each example E in the sample:
  1. Read E; extract every `use echo_agent::...` / `use echo_core::...` import
     plus every method/variant/field referenced.
  2. For each symbol S: grep the current tree for S's definition or pub re-export.
  3. Record RESOLVES / MISSING with file:line of the definition.
```
