## Claim

The frontend dependency inventory (`echo-agent-cli/web-frontend/
package.json`) uses current, maintained versions of all major
packages, with no deprecated packages. One manifest-hygiene issue
exists: `@tailwindcss/vite` is declared in both `dependencies` and
`devDependencies` at slightly different version ranges.


## Expected Result

Per AGENTS.md "代码清理:无需兼容,过时代码可直接删" and general
manifest hygiene: each package should appear in exactly one of
`dependencies` or `devDependencies`, at a single version range.
Build-time tooling (Vite plugins, test runners, type definitions)
should be in `devDependencies`. All packages should be current and
non-deprecated.

- `@tailwindcss/vite` appears in **both** `dependencies` (`^4.1.4`)
  and `devDependencies` (`^4.1.8`). npm will resolve both to the
  same hoisted version, but the duplicate declaration with differing
  ranges is a manifest-hygiene issue. As a Vite plugin used at build
  time, `devDependencies` is the correct location.
