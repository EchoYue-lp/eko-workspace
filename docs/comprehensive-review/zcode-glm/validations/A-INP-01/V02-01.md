## Claim

Every chat/steer/channel/REPL entry point that produces user text for
the agent routes through `PreparedUserTurn::build`
(`prepared_turn.rs:260`) before reaching `drive_chat` /
`agent.steer_input`. Specifically, the five-entry field matrix named in
A-INP-01 covers all live paths and there is no hidden fourth raw-text
constructor still in use.

## Deviations

The bypass at `events.rs:1438` is itself a finding (A-INP-01-P2-01),
not an environmental deviation. The validation's claim is partially
falsified: not every `/steer` route normalizes through
`PreparedUserTurn`. The five primary chat/steer build sites exist as
predicted, but the input-box `/steer` fast path is a sixth, divergent
route.

## Conclusion

Supports the existence and identity of the five-entry matrix, but
uncovers one bypass that becomes A-INP-01-P2-01. The four non-TUI-steer
chat paths and both Tauri paths (chat + steer) are correct.
`drive_chat` itself only ever receives a `PreparedUserTurn` — its
single-merge-point invariant holds.
