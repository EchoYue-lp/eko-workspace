## Claim

`AgentRuntime::bootstrap` (`runtime.rs:73`) is the single composition root for
the EKO agent stack, and it constructs every core agent-side service exactly
once per process. This validation enumerates those services and confirms
uniqueness.

## Method

Static inspection of the bootstrap method body. Working directory:
`/Users/ls/MyWork/code/ylp_agent_learn/lp-agent`.

```text
1. Read echo-agent-cli/echo-agent-app-core/src/runtime.rs:1-497 (struct + bootstrap).
2. Enumerate every service/object constructed inside bootstrap() in source order.
3. grep the whole echo-agent-cli tree for a second bootstrap implementation:
   grep -rn "fn bootstrap" --include="*.rs" echo-agent-cli
4. Confirm both live callers (main.rs:168 headless, desktop.rs:160 GUI) invoke
   AgentRuntime::bootstrap exactly once each.
```

## Expected Result

- Exactly one `bootstrap` method on `AgentRuntime`.
- Both entries call it exactly once.
- The constructed services form a documented, ordered list.
