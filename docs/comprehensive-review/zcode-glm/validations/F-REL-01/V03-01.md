## Claim

The reliability primitives honor the project's no-panic conventions under edge
cases: `Duration` arithmetic is safe, `AtomicU32` counters are safe, and
`TokenBudget::allocate` handles large windows without panicking.

## Method

Source-level invariant inspection against AGENTS.md Rust hard constraints
(UTF-8 safety, no-panic API usage).

```text
1. Inspect circuit_breaker.rs for Duration arithmetic and AtomicU32 usage —
   confirm no unwrap/expect/panic on transitions.
2. Inspect retry.rs delay_for for Duration arithmetic — confirm no byte slicing
   and no panicking arithmetic.
3. Inspect budget.rs allocate (around line 90) for usize arithmetic — check
   checked_add / saturating_* usage.
```

## Expected Result

- `CircuitBreaker`: `Duration` comparisons and `AtomicU32` loads/stores use
  safe operations; no `unwrap`/`expect`/`panic`.
- `RetryPolicy::delay_for`: `Duration` math is safe; jitter does not panic.
- `TokenBudget::allocate`: uses `checked_add` / `saturating_*` for usize
  arithmetic so that very large `total_window` values cannot wrap or panic.
