## Claim

Across both repositories, type/trait/enum names defined as `pub` in BOTH
`echo-agent` and `echo-agent-cli` are enumerated and each classified as
(a) true semantic duplicate authority, (b) legitimate wire projection /
adapter with explicit conversion, or (c) coincidental name reuse for an
unrelated concept. No parallel task/plan/todo/store/validator/CRUD
authority exists.

## Method

Extract every `pub struct|enum|trait <Name>` definition from each repo,
intersect the name sets, and for each shared name locate both definitions
and read enough of each to classify the relationship.

```text
cd /Users/ls/MyWork/code/ylp_agent_learn/lp-agent
grep -rhoE "^pub (struct|enum|trait) [A-Za-z_][A-Za-z0-9_]*" \
  echo-agent --include="*.rs" | awk '{print $NF}' | sort -u > /tmp/fw_types.txt
grep -rhoE "^pub (struct|enum|trait) [A-Za-z_][A-Za-z0-9_]*" \
  echo-agent-cli --include="*.rs" --exclude-dir=target | awk '{print $NF}' | sort -u > /tmp/cli_types.txt
comm -12 /tmp/fw_types.txt /tmp/cli_types.txt
# then per-name: grep -rnE "^pub (struct|enum|trait) <Name>\b" in both repos
```

Counts: framework has 1143 distinct pub type names (1095 struct + 194 enum
+ 65 trait, with overlap); CLI has 482. CLI defines only 3 traits
(`Widget`, `SlashCommand`, `ChatSink`) — none duplicates a framework trait.

Search excluded `target/`. The shared-name set is small enough (20 names)
to classify every member.

## Expected Result

  traits; it does not redefine them).
- Zero parallel task/plan/todo model, store, validator, or CRUD tool in the
