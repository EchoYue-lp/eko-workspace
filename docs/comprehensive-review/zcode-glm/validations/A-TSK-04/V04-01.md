## Expected Result

- All four subsets pass with 0 failures.
- Boot recovery: Running run + Running todo → Paused run + Pending
  todo, with the durable subagent result preserved for the exact
  execution_id.
- Mutating-in-doubt: a non-replay-safe tool/subagent in flight at
  crash time → Blocked todo + RecoveryBlocked barrier → resume
  refuses.
- Barrier crash-safety: `RecoveryResolved` without the todo mutation
  → `list_recovery_blockers` re-synthesises the barrier from the
  Blocked todo projection.
- Retry budget: `retry_blocked_task` enforces `retry_count <
  max_retries` and bumps attempt under the per-run lock.
- Stale-claim rejection: a claim that no longer matches the persisted
  task state produces `Superseded` with no event appended.
- Stale-revision rejection: `claim_task` / `compare_and_commit` with
  a stale `expected_revision` produces `ReloadSnapshot` /
  `Err(PlanConflict)` with no event appended.
- Illegal-transition rejection: terminal → non-terminal produces
  `Err(IllegalTransition)` with no event appended.
- Cycle rejection: a cyclic patch produces `Err(InvalidPlan)` with no
  event appended.
- Concurrent append: same-run concurrent appends produce strictly
  increasing unique seqs.
- Concurrent atomic_write: no tmp-file collision.
- Projection parity: the event-fold rebuild matches the persisted
  projection after a full lifecycle.
- Hook terminal distinction: TaskCancelled → Cancelled,
  TaskTimedOut → TimedOut, not collapsed.
- Bounded queue: backpressure without dropping.
