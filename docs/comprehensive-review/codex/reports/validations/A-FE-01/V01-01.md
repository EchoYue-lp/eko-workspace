## Claim

Every `#[ts(export, rename = ...)]` application DTO has a correspondingly named generated TypeScript file, and canonical TaskRuntime endpoints use those generated DTOs instead of redefining TaskRun, PlanTask, or SubagentRun.

## Method

```text
1. Search echo-agent-app-core for all `#[ts(export, rename = "...")]` declarations.
2. Sort unique export names and check for `web-frontend/src/generated/<name>.ts`.
3. Search frontend endpoints/stores/components for TaskRun, TaskPlan, PlanTask,
   RuntimeTaskEvent, RuntimeArtifact, and SubagentTaskResult imports.
4. Search for same-name handwritten TaskRun/PlanTask/SubagentRun declarations.
```

## Expected Result

All exported DTO files exist and canonical TaskRuntime concepts have one Rust authority plus generated TypeScript bindings.

## Result

- Exit code: 0
- Duration: static inspection
- Summary: 79 unique renamed exports were found and none lacked a same-name generated file. `taskRuntimeApi`, `taskRuntimeStore`, task components, and the Subagent projection import canonical task/runtime types from `../generated`; no second TaskRun, PlanTask, or SubagentRun domain declaration was found.
- Log/artifact: `echo-agent-cli/echo-agent-app-core/src/tasks/task_runtime/types.rs`; `echo-agent-cli/web-frontend/src/api/endpoints.ts:48`; `echo-agent-cli/web-frontend/src/stores/subagentRunStore.ts:18`

## Conclusion
