## Claim

Cancelling `ChatRequest.cancel_token` interrupts a pending non-stream
`OpenAiClient::chat` call and prevents a later response.

## Method

```text
env CARGO_TARGET_DIR=/private/tmp/f-llm-02-target cargo run --offline --quiet --bin nonstream_cancel
```

The loopback server delays 350 ms; the request token is cancelled after 30 ms.

## Expected Result

The call returns a cancellation outcome within 150 ms and never returns the
delayed body.

## Result

- Exit code: 1
- Duration: 0.99 seconds
- Summary: the call completed after 355.98 ms with successful content `late`.
- Log/artifact: `/private/tmp/f-llm-02-probe/src/bin/nonstream_cancel.rs`

## Deviations

The public field comment currently narrows interruption to streaming, but the
field itself is accepted by the unified `chat` request and is silently ignored
instead of rejected on non-stream calls.

## Conclusion

The unified cancellation invariant is false. This supports F-LLM-02-P1-04.

## Follow-Up

Race cancellation against non-stream send/body reads, or split the API so an
unsupported control cannot be silently accepted.
