## Claim

When `events.jsonl` contains a valid RunCreated event but `run-state.json` is missing, the live read path does not rebuild the projection and returns no run.

## Method

Compile `/private/tmp/a-tsk-01-fault-fixture/src/main.rs` directly against the already-built app-core rlib, then execute its `missing_projection` scenario. The fixture creates a run through `TaskRuntimeStore`, deletes only `run-state.json`, reads both events and `get_run`, and exits 0 only when one durable event remains but `get_run` is `None`.

```text

/private/tmp/a-tsk-01-fault-fixture/fault-fixture missing_projection
```

## Expected Result

The scenario should print `events=1 get_run=None`, proving operational reads do not use the declared event authority to repair a missing projection.

## Result
