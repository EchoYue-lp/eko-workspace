## Claim

Path confinement for a not-yet-created target cannot be bypassed through an
existing in-scope symlink followed by a missing directory.

## Method

```text
1. Inspect resolve_path textual normalization, target canonicalization, parent
   canonicalization, and fallback branches.
2. Symbolically evaluate base/link/new/file where base/link is a symlink to an
   out-of-scope directory and base/link/new does not yet exist.
3. Trace the returned path into write_file create_dir_all/write and move_file
   create_dir_all/rename.
```

## Expected Result

Resolution either canonicalizes the deepest existing ancestor and proves it is
inside the canonical base, or rejects the target.

## Result

- Exit code: not-applicable (static path-state proof)
- Duration: approximately 3 minutes
- Summary: when target canonicalization fails, only the immediate parent is
  canonicalized. If that parent is also missing, resolution returns the
  textually normalized path without examining the existing symlink ancestor.
  Subsequent directory creation and write/rename follow the symlink outside the
  intended root.
- Log/artifact: `echo-tools/src/files/mod.rs:72`,

## Conclusion

The confinement invariant fails for a statically reproducible path shape.
Supports `F-EXT-02-P1-01`. It does not prove behavior on every platform or
eliminate the separate symlink-swap race after resolution.

## Follow-Up

absolute and relative inputs, create/write/append/move, and a swap race using a
handle-relative filesystem API.
