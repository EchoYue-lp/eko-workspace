## Claim

intermediate result materialization for local repositories.

## Method

```text
1. Trace allocation before pagination in read_file, diff, grep, code_search,
   repo_map, and Git output.
2. Record per-file, aggregate-result, traversal, and subprocess-output caps.
3. Distinguish model-visible output pagination from process memory bounds.
```

materialized, with continuation preserving exact query identity.
