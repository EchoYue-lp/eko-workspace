## Result

- Exit code: 0 for the inspection; claim failed
- Duration: not recorded
- Summary: every instance loads a private full-file snapshot into its own
  `RwLock`; no file lock, generation check, or reload exists. After A writes
  `S+a`, B writes stale `S+b` over it, losing `a`. Both also use the same fixed
  `<path>.tmp`, so overlapping flushes can truncate/remove each other's temp
  file. The file is synced before rename, but the parent directory is not synced.
  The framework docs explicitly recommend `memory_path("./store.json")` for

- Log/artifact: this report

## Deviations

`Arc<FileStore>`; it does not serialize separately constructed instances.
