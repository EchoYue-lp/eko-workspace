## Claim

A failed direct hook activation can be adopted by TriggerSupervisor and is
consumed only by the turn that produced it.

## Method

Trace `fire_lifecycle_hook` failure retention, prepare-time cache writes,
TriggerSupervisor fast paths/fusion, and the outer router threshold.

## Expected Result

The current turn's hook request either activates directly or reaches the router
with an accepted confidence; every classify path consumes/clears that turn's slot.

## Result

- Exit code: not-applicable (static inspection).
- A failed direct activation is intentionally retained in the shared slot.
- Supervisor converts it to SkillRequired at confidence 0.6, while the live EKO
  router rejects every skill decision below 0.7. The documented fallback cannot
  activate the skill.
- Keyword and LLM high-confidence paths return before `guard.take()`, so the slot
  is not consumed and may be observed by a later turn that itself falls back.

## Deviations

Execution serialization prevents concurrent turns on one Agent, but does not
prevent stale sequential ownership.

## Conclusion

Failed. Supports F-INTENT-01-P1-01.

## Follow-Up

Replace the shared optional slot with a turn-scoped typed input and one threshold
authority; consume it in a finally-style step on every decision path.
