stable Workflow/Run identity, not on trusting an in-memory status snapshot.

## Deviations

Temporal is a distributed durable-execution platform, not a coding-agent product. Its
invariants are useful for orchestration but its full storage architecture is not an EKO
requirement.

## Conclusion

Supports durable event authority, stable execution/attempt identity, idempotent replay,
and explicit terminal states as generic orchestration mechanisms.
