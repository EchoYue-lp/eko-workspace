preserve framework/application boundaries, and apply the repository's local
extension threat model without adding online-service permission gates.

## Method

- Streamable HTTP pending/session/notification fields and every sender/receiver,
  202, synchronous response, notify, timeout and close branch;

  Tool conversion, result mapping and exposed-name encoding;

- LSP read framing, pending requests, process state, wire enums, parse fallbacks,
  document/URI/version/position conversion;

## Expected Result

Every finding is directly reachable through a public or live adapter path,
protocol-specific rather than a duplicate generic Tool defect, and has an
appropriate reusable-framework remediation owner.

## Result

- Exit code: 0 for static read and integrity commands.
- The HTTP 202 path registers pending senders but the transport has no response
  reader/router; advertised client capabilities likewise have no handlers.
- SSE/stdio cleanup/reconnect observations and MCP list/map/result divergence are
  consistent with the sampled ownership model.
- LSP allocates from unbounded Content-Length, uses string serde for numeric wire
  enums, and converts parse errors into empty successful collections.
- A2A cancellation updates projection/token state without passing the token into
  Agent execution; Error payloads are ignored by the streaming match and EOF can
  then write Completed. Duplicate task IDs replace current map ownership.
- The A2A client decodes each network chunk independently and its stream item
  type cannot surface transport/decode errors.
- MCP sanitizer collisions, panic/overflow and LSP document conversion defects
  were confirmed.
- The stdio argv policy rejects every `-o*` independent of command semantics.
  This is classified as overbroad local-extension policy; the remedy is a light
  malformed-input boundary, not more permission gating.

## Deviations

regressions. LSP UTF-16 position impact remains medium confidence as the report
states; its URI/version/cast findings are source-conclusive.
