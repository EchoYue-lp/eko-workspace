## Expected Result

Teammate should be observably parallel at its normal dispatch API and should
provide the documented message-passing coordination.

## Result

- Exit code: 0
- Duration: static inspection
- Summary: low-level `dispatch_teammate` spawns and returns a cancellable join
  handle, but normal `dispatch` immediately consumes and joins it. The mode has
  no mailbox field or coordination API; Mailbox belongs to the separate Team
  object and is not wired to this handle. The model-facing schema nevertheless
  calls Teammate a parallel mailbox agent.
- Log/artifact: this report

## Deviations

Using the independent `background` flag can make the whole dispatch
non-blocking, but that does not add mailbox semantics and applies to every mode.

## Conclusion

The claim failed and supports F-SUB-02-P2-01. The low-level spawn handle is real,
but the advertised mode distinction is not realized by the common dispatch API.
