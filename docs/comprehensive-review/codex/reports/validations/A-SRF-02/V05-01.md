## Claim

PTY session identity is admitted atomically and terminal sessions are removed
and killed at process exit, window close, reader EOF, and explicit tab close.

## Method

```text
1. Trace create_terminal -> TerminalManager::create -> PtySession::spawn ->
   reader thread -> events.
2. Trace close_terminal, reader EOF/error, drawer close/tab close, Tauri .run
   return, and `close_all` callers.
3. Inspect DashMap admission sequence and portable-pty 0.8.1 Child/ChildKiller
   semantics from installed source.
```

## Expected Result

A terminal ID admits at most one shell; every terminal boundary removes the
entry and awaits process termination without orphaning a child/read thread.

## Result

- Exit code: not-applicable
- Duration: static lifecycle table
- Summary: duplicate admission uses separate `contains_key` and `insert`
  (`terminal.rs:224-230`), so concurrent same-ID creates can both spawn; the
  later insert replaces the only manager reference to the first shell.
  EOF/error only emits `terminal-exit` and never removes the entry
  (`terminal.rs:136-169`). `close_all` removes entries but spawns unjoined kills
  and has no production caller (`terminal.rs:256-266`). Desktop teardown cancels
  background services and browser runtime but has no TerminalManager handle
  (`desktop.rs:255-268`). Explicit tab X calls `close_terminal`; the drawer X
  merely hides the drawer and deliberately keeps tabs/sessions.
- Log/artifact: installed portable-pty source
  `/Users/ls/.cargo/registry/src/rsproxy.cn-e3de039b2554c837/portable-pty-0.8.1/src/lib.rs`

## Deviations

Hiding the drawer while keeping sessions may be intended minimize behavior,
despite its misleading `Close terminal` tooltip. The source-conclusive defects
are same-ID non-atomic admission, stale EOF entries, and absent application-exit
cleanup. Exact OS survival after parent exit is platform/shell dependent.

## Conclusion

The claim fails and supports A-SRF-02-P1-03 and A-SRF-02-P1-04.

## Follow-Up

Add deterministic barriers around duplicate create, EOF, kill failure, window
close, and app exit; assert no untracked pid, stale entry, or unjoined cleanup.
