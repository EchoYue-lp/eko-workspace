## Claim

Entry-point options select one coherent project root for instructions,
Subagent discovery, worktree setup, tool execution, memory, and TUI file
projection.

## Method

Trace `Args.project` from argument parsing into `AgentCreateParams`, then inspect
the independent consumers of `project` and `working_dir` in
`create_agent_with_diagnostics`, the CLI project context, and TUI file
collection. Compare GUI's synthetic argument parse with headless parsing.

```text
rg -n "project: args\.project|working_dir: None|subagent_project_root|memory_workspace_root|collect_project_files|parse_from" echo-agent-cli/src echo-agent-cli/echo-agent-app-core/src -g '*.rs'
```

## Expected Result

When `echo-agent-cli --project /target` is selected, `/target` is the working
directory for shell/file/git tools, project-scoped memory and artifacts,
Subagent/worktree discovery, CLI coding commands, and TUI file completion.

## Result

- Exit code: `0`
- Duration: under 1 second
- Summary: headless boot passes `project: args.project.clone()` but hard-codes
  `working_dir: None` (`src/main.rs:153-165`). `project` selects the Subagent
  catalog and worktree discovery root (`infra.rs:233-251`, `:387-414`), while
  only `working_dir` is installed into `ReactAgent` tool contexts
  (`infra.rs:334-339`) and selects project-scoped memory (`:341-356`). CLI
  coding commands separately use `--project` (`src/cli/repl.rs:118-127,
  :183-189`), but TUI file completion still scans `.`
  (`src/tui/mod.rs:1966`). Thus one session can display/load `/target` project
  context while agent tools and memory operate in the launch directory and TUI
  completion exposes files from that other directory.
- Log/artifact: none

## Deviations

GUI starts without a workspace and later has a dedicated workspace-switch path
that propagates working directory to primary and pooled agents. This result is
about the live headless `--project` option, not GUI workspace switching.

## Conclusion

The claim is false. This supports `A-BOOT-01-P1-01`: explicit project selection
does not establish a single execution root.

## Follow-Up

`A-CFG-01` should consume this finding when defining one project/workspace
resolution contract. Regression coverage must launch from directory A with
`--project` directory B and assert instruction, tool, memory, worktree, and TUI
file roots all resolve to B.
