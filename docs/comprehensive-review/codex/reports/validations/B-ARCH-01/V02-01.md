## Claim

The root facade's public modules and re-exports can be mapped to their actual
owner crates, including any incomplete direct-workspace escape hatch.

## Method

All eight crate roots were read in full. Root `src/lib.rs` and its adapter
modules were searched for `pub mod` and `pub use echo_*`; each adapter was
checked for whether it re-exports or adds root-owned behavior.

```text
nl -ba src/lib.rs
for f in echo-{core,macros,execution,tools,integration,state,orchestration}/src/lib.rs; do nl -ba "$f"; done
rg -n '^pub use echo_|^\s*pub use echo_' src/lib.rs src/*.rs src/*/mod.rs
rg -n 'echo_agent::workspace' README.md docs echo-*/README.md examples tests
```

## Expected Result

The facade presents stable top-level adapters and its explicitly documented
`workspace` module exposes every split member named by the workspace topology.

## Result

- Exit code: 0
- Duration: under one second
- Summary: core contracts surface through agent/error/llm/retry/tokenizer and
  tool submodules; execution owns sandbox, skills, and `ToolManager`; state owns
  audit/compression/memory; integration owns providers/MCP/LSP/channels;
  orchestration owns workflow/human-loop/tasks/scheduler; domain implementations
  surface selectively through `tools`; macros are re-exported at crate root.
  The `workspace` module exposes core, execution, integration, orchestration,
  and state only. It omits tools and macros although both are direct workspace
  dependencies. Repository-wide usage found one live consumer of the escape
  hatch (`demo70_scheduler`) and no alternative `workspace::tools` path.
- Log/artifact: source anchors are in `B-ARCH-01.md`

## Deviations

The facade is intentionally not a pure re-export crate: the root owns the ReAct
engine, evolution, context, and workflow DSL/loader. This validation maps that
fact but does not judge those modules' internal correctness.

## Conclusion

Most owner-to-facade paths are explicit and thin, but the advertised direct
workspace access is incomplete. This supports `B-ARCH-01-P2-02`.

escape hatch is retained and completed or removed as migration-only API.
