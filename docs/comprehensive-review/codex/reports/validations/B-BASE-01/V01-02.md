## Claim

The checked-in manifests and lockfiles resolve to a complete, unambiguous
inventory of the current Rust workspaces and standalone frontend package.

## Method

Both repositories were scanned for manifests outside ignored build/worktree
directories. Package counts and names were computed from Cargo's normalized
JSON rather than hand-counted. The full framework root manifest, including
lines 163-372, was read as a cross-check.

```text
find . -name Cargo.toml -not -path './target/*' -not -path './.worktrees/*' | sort
cargo metadata --no-deps --locked --format-version 1 |
  jq '{package_count:(.packages|length), package_names:[.packages[].name]}'
find . -maxdepth 2 -name package-lock.json -o -name yarn.lock -o -name pnpm-lock.yaml | sort
awk '/^\[\[example\]\]/{n++} END{print n+0}' echo-agent/Cargo.toml
```

Environment: macOS, Cargo 1.97.1, Rust 1.97.1. No compilation feature set was
selected because this validation concerns manifest topology.
