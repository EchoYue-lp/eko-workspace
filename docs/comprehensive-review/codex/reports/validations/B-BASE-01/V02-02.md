## Claim

Every declared Cargo feature and optional dependency can be counted and mapped
from normalized metadata, and EKO does not enable the framework SQLite feature.

## Method

Counts were computed directly from each repository's
`cargo metadata --no-deps --locked --format-version 1` JSON. Per-package arrays
were retained to reconcile every aggregate. Relative path declarations were
searched independently across both repositories.

```text
cargo metadata --no-deps --locked --format-version 1 | jq '{
  feature_entries:([.packages[].features|keys[]]|length),
  optional_dependency_records:([.packages[].dependencies[]|select(.optional)]|length),
  optional_by_package:[.packages[]|{name,
    count:([.dependencies[]|select(.optional)]|length),
    names:[.dependencies[]|select(.optional)|.name]}],
  path_dependency_records:([.packages[].dependencies[]|select(.source==null)]|length)
}'
rg -n 'path\s*=\s*"(/Users/|.*worktrees)' echo-agent echo-agent-cli \
  -g Cargo.toml -g '!target/**' -g '!.worktrees/**'
```

Environment: macOS, Cargo 1.97.1, Rust 1.97.1. Standalone feature compilation
is deferred to `F-FEAT-01` and `Q-FW-02`.

## Expected Result

Aggregate counts equal the sum of per-package records; path dependencies are
relative; neither EKO framework dependency selects `sqlite`.

## Result

- Exit code: 0
- Duration: under one second
- Summary: the framework has 65 per-package feature entries and 46 optional
  dependency records: core 3, macros 0, execution 0, tools 22, integration 2,
  state 1, orchestration 1, facade 17. It has 14 internal path-dependency
  records. EKO has 7 per-package feature entries (6 unique names), 19 optional
  dependencies (all on the root package), and 6 path-dependency records when
  the app-core dev dependency is counted separately. Both EKO packages use
  `default-features = false` for `echo-agent`; app-core selects 15 named
  framework features and the root selects 5, with no `sqlite`. No absolute or
  worktree Cargo path was found.
- Log/artifact: the exact jq reduction is recorded in Method

## Deviations

The framework facade `full` feature omits six declared local markers:
`workflow`, `sandbox`, `semantic-memory`, `macros`, `provider-factory`, and
`multimodal`. Whether those markers are live and whether omission is defective
requires cfg/source and compilation evidence from `F-FEAT-01`.

## Conclusion

The feature/dependency topology is machine-reconciled, and the CLI manifest
boundary satisfies the no-SQLite invariant. This does not prove feature
isolation or source cfg consistency.
