## Claim

GUI file documents and pending requests retain workspace identity across a
workspace switch, so a draft can only be saved to the workspace that produced
its base revision.

## Method

```text
Trace workspaceStore.switchTo into the Tauri switch command and AppState. Then
trace fileStore tree/openFiles/selectedFile/documents/diffHunks/changes,
FileBrowser polling, saveSelected, filesApi.write, get_workspace_root, and
write_workspace_file's revision check. Evaluate two workspaces containing the
same relative path and equal base bytes, followed by a dirty draft and switch.
```

revision. Switching must cancel or generation-fence old requests and either
retain a workspace-bound draft explicitly or block/clear it before rebinding.
