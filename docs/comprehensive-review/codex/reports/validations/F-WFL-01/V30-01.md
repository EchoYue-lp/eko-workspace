## Result

- Exit code: 0 for static read and integrity commands.
- Public resume consumes the supplied clonable Checkpoint value without graph,
  revision, run, attempt, store-membership or atomic claim validation; deletion
  is deferred until a successful terminal path.
- Interrupt-after maps a parallel continuation to only its convergence node,
  so resume skips every target. Rejected/Deferred return `Completed` and leave
  the same checkpoint available.
- Builders silently replace/collapse duplicate node IDs and omit several finish,
  interrupt and fan-out reference validations.
- Graph fan-out loops serially and merges each sibling before forking the next;
  resume instead mutates shared state directly, so order/failure/restart differ.
- File store joins public IDs into paths without opaque-key validation, shares a
  predictable temp path, silently omits corrupt list entries and ignores clear
  deletion failures.
- Concurrent and DAG workflows return on the first joined error while dropped
  remaining JoinHandles detach; no common in-node deadline/cancel contract exists.
- ToolApproval/UserRequest have no live graph producer/consumer, and the
  `workflow` feature is an empty gate over an always-compiled surface.
- The sampled direct indexing, unchecked accounting and public UTF-8 byte-slice
  example support the narrowly scoped P3 finding.
