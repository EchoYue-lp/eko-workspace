## Claim

All EKO app-config definitions, discovery APIs, load/save authorities, and live
callers can be enumerated without relying on historical documentation.

## Method

```text
1. Search both repositories for AppConfig, ModelConfig, ModelProviderConfig,
   ConfiguredModel, config_search_paths, load_config, load_config_file,
   save_config, ConfigDiscovery, apply_env_overrides, and ECHO_AGENT_CONFIG.
2. Read each definition and every non-test caller.
3. Classify definition, display-only discovery, startup load, mutation/save,
   and watcher/reload paths separately.
```

## Expected Result

One source authority should own effective path selection and be reused by
startup, discovery, save, and reload.

## Result

- Exit code: 0

- Summary: definitions and callers were exhaustively mapped. Startup uses

- Log/artifact: task report current-path map
