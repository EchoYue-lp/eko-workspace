for all catalog Q tasks.

```text

count passed, failed, inconclusive, not_run, and unknown values;
sum per-task counts and compare with total files.
```

## Deviations

These are validation-report/attempt counts, not shell-command counts. A static
validation may contain multiple read-only commands; a single `not_run` may
represent a future matrix (for example 57 feature checks or 27 example groups).

`not_run` gate passed or that every `failed` status is a nonzero command.
