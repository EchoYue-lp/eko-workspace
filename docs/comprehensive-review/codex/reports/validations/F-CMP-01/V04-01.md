## Expected Result

contiguous immediately after the assistant message; no inserted user/system
message splits that protocol group.

## Result

- Exit code: 0

  dangling calls. Adaptive L1 Fold can instead transform
  `assistant(A,B,C), result(A), result(B), result(C)` into
