## Expected Result

Every accepted defect is reachable through framework public or live EKO
adapter paths, does not infer deadness merely because EKO omits an option, and
assigns product policy to EKO while retaining reusable lifecycle in the
framework.

## Result

- Exit code: 0 for static read and integrity commands.
- Discovery copies file descriptors into two registries. Model activation
  mutates the progressive copy, while public activation and resume mutate only
  the catalog copy; the invocation snapshot merely merges their current names.
- Dependency discovery logs malformed graphs but commits them. Recursive
  activation has no visiting guard and inserts a node only after descendant
  activation, so a cycle has no terminal branch.
- `SkillDescriptor.location` is the `SKILL.md` file, while baseline injection
  appends another `SKILL.md`. The live EKO caller then logs injection success
  without observing which baselines were actually read.
- Same-scope traversal consumes unsorted `read_dir` entries and first-name wins;
  ordinary rediscovery skips an already installed descriptor and retains stale
  associated state.
- Code-Skill registration extracts tools and prompt, records only `SkillInfo`,
  and drops the lifecycle object. No production caller invokes the public Skill
  `shutdown` hook or reverses its prompt/tool ownership.
- Individual resource reads are bounded, but descriptor file/body, aggregate
  catalog and resource-entry counts are not; documented metadata limits are
  warning-only or absent.
