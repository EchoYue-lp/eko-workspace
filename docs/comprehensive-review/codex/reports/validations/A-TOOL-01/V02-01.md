## Expected Result

One availability result removes `run_code` from main and writer Agents when unavailable; readonly Subagents never register it; pooled Agents cannot reintroduce a less-constrained manager/tool catalog.

- AgentPool builds through the same EKO constructor before replacing its ToolManager and sandbox manager with the already-probed primary shared resources.
- Existing tests cover removal and writer manager inheritance.
