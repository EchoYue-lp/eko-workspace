## Claim

Potentially sensitive user/tool content is redacted and bounded before it leaves
the local application through a user-configured webhook.

## Method

```text
Trace ToolCall args, ToolError error, Agent Error, and cron result text into
WebhookEvent and serde_json serialization. Search the webhook/observer boundary
for secret scanning, recursive redaction, content policy, and character/record
bounds. Distinguish normal local user extension from a public-service threat
model; inspect only accidental secret disclosure and framework-bug risks.
```

## Expected Result

Known credential/token patterns are removed at the outbound boundary, and all
content fields have UTF-8-safe size limits appropriate to summary events.

## Result

- Exit code: 0
- Duration: static source-to-sink inspection; not timed
- Summary: tool arguments are serialized verbatim and character-truncated to
  240, but never redacted. Tool and Agent errors are neither redacted nor
  bounded. The payload is then sent to every matching configured endpoint.
  Endpoint HMAC protects authenticity but not content selection. The 240-character
  operation is UTF-8 safe. No secret scanner or outbound payload policy appears
  anywhere in this path.
- Log/artifact: this report

## Deviations

This finding does not treat a user-configured local extension as hostile and
does not recommend permission gates. It addresses accidental credential
propagation to a destination the user selected for operational summaries.
