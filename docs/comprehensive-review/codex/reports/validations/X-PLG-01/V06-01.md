## Claim

The Skill set used by EKO intent classification should change with successful
plugin Skill load/reload/unload rather than remain a bootstrap snapshot.

## Method

```text
Trace AgentRuntime::bootstrap ordering from initial plugin load through
SkillDescriptor enumeration, KeywordClassifier, LlmIntentClassifier,
TriggerSupervisor and IntentRouter installation. Search all writes/consumers of
AgentRuntime.keyword_classifier and all later set_intent_router/rebuild calls.
Trace committed framework IntentRouter reachability in streaming and
non-streaming ReAct paths.
```

## Expected Result

Successful plugin Skill generation changes should atomically rebuild/swap the
classifier or make it consult the live authoritative descriptor set.

## Result

- Exit code: 0
- Duration: static data-flow inspection; not timed
- Summary: initial plugin load precedes classifier construction, so startup
  plugins are included. Keyword triggers and LLM Skill descriptions are then
  copied into a TriggerSupervisor and installed as one IntentRouter on the
  primary Agent. `keyword_classifier` is stored on AgentRuntime but has no later
  reader or updater; no plugin mutation path rebuilds or swaps the router. The
  framework uses this router on both streaming and non-streaming live paths.
  Consequently a newly loaded plugin Skill is absent from automatic routing and
  a removed/renamed Skill remains classifiable until restart.
- Log/artifact: this report
