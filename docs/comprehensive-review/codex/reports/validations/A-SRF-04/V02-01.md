## Claim

The live CLI and channel chat callers preserve prepared-turn identity, shared
memory/tool configuration, TaskRuntime resources, Subagent reachability, HITL,
and canonical typed events up to the surface sink.

## Method

```text
Trace main -> bootstrap -> AgentPool/TaskRuntimeStore -> run_cli_mode/run_channels_mode
-> PreparedUserTurn -> ChatResources -> drive_chat -> ChatDriverEvent -> surface sink.
Inspect tool registration, conversation/turn/run IDs, attachment refs,
interaction mode, cancellation token, review/memory layer, webhook, and HITL.
```

## Expected Result

The adapters reuse one fully configured agent/runtime and carry complete
identity and product resources rather than constructing reduced agents.

## Result

- Exit code: not-applicable
