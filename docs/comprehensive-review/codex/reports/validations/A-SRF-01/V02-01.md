## Claim

The default binary entry reaches `run_tui` with the same core runtime services
needed for chat, tasks, Subagents, HITL, persistence, browser, plugins, and cron.

## Method

```text
Trace src/main.rs main -> run_tui_or_cli_entry -> AgentRuntime::bootstrap ->
headless TaskRuntime registration/pool binding -> TUI HITL provider swap ->
start_headless_services -> run_tui; then map every run_tui argument into TuiApp
and the event loop.
```

## Expected Result

The default TUI entry should provide live services rather than `None` as a
product-mode decision, and should clean up owned background services on exit.

## Result

- Exit code: 0
- Duration: static inspection; not timed
- Summary: default invocation selects TUI; bootstrap constructs one Agent
  runtime, registers TaskRuntime tools, binds `task_execute` to the shared pool,
  replaces the REPL HITL provider, starts shared headless services, and passes
  all service handles into `run_tui` (`src/main.rs:111-199`, `:239-303`).
  `run_tui` installs those handles on `TuiApp` (`src/tui/mod.rs:1882-1965`) and
  main shuts down task hooks/browser/config cancellation (`src/main.rs:329-335`).
