## Claim

The neutral request/response field and enum-variant matrix can represent and
round-trip all declared message, tool, thinking, usage, cache, error, and
cancellation facts.

## Method

Build a field-by-field matrix from `ChatRequest`, `ChatResponse`, `ChatChunk`,
`Message`, `MessageContent`, `ContentPart`, `ToolCall`, `ToolChoice`,
`ResponseFormat`, `ThinkingConfig`, `Usage`, and OpenAI chunk types. For each
field, inspect serialization shape, provider mapping, streaming representation,
and runtime reconstruction.

## Expected Result

Every declared variant has a type-correct request representation and every
provider response fact has a neutral response/stream slot.

## Result

- Exit code: not-applicable
- Duration: not recorded
- Summary: message text/parts, request temperature/max/tools/thinking/user ID,
  and basic usage have slots. The matrix fails for named `ToolChoice` (JSON
  value versus string field), stream response ID/candidate index/multiple
  candidates, Anthropic thinking output, typed malformed-stream errors, and
  non-stream cancellation semantics.
- Log/artifact: none

## Deviations

Provider-specific raw metadata is not required to become a first-class field,
but `ChatResponse.raw` explicitly promises access while Anthropic fabricates an
empty OpenAI-shaped value.

## Conclusion

The neutral contract is not lossless. This supports F-LLM-01-P1-03,
F-LLM-01-P1-04, F-LLM-01-P2-08, and F-LLM-01-P2-09.
