## Claim

Telemetry initialization is no-panic, repeatable or explicitly single-use, and
shutdown flushes the exact trace and metrics providers initialized by the facade.

## Method

```text
1. Trace init_telemetry through exporter, provider, subscriber and metrics creation.
2. Trace ownership into tracing layer, OnceLock instruments and shutdown_telemetry.
3. Compare local providers with OpenTelemetry global provider calls.
4. Inspect feature-on/off EKO paths and upstream tracing-subscriber/OpenTelemetry
   lifecycle API source already available in the local cargo registry.
```

## Expected Result

Initialization failure is typed rather than panic; caller receives a handle or
single-use contract; shutdown flushes both actual providers and reports errors.

## Result

- Exit code: 0
- Duration: static lifecycle and dependency-source inspection
- Summary: both subscriber branches call `.init()`, whose dependency contract
  panics when a global subscriber/logger is already set despite this facade
  returning Result. The trace provider is local and never installed globally;
  shutdown replaces only the unrelated global provider. The meter provider is
  not retained or shut down, while METRICS is a non-resettable OnceLock. Metrics
  init failure is logged but init_telemetry still returns success. EKO's feature-on
  adapter discards that Result; feature-off uses its own logging initialization.
- Log/artifact: this report

## Deviations

No exporter/network behavior was exercised. Provider ownership and panic/flush
semantics are explicit in current and dependency source.

## Conclusion

The telemetry lifecycle invariant fails and supports F-OPS-01-P1-06.

## Correction (2026-08-12)

The Result summary's phrase “meter provider is never retained or shut down” is
imprecise. Local `opentelemetry_sdk` source establishes that dropping the last
`SdkMeterProvider` handle automatically shuts down its pipelines. Because
`init_metrics` does not retain or return that handle, this automatic shutdown
occurs when initialization returns; the global instruments then refer to a
pipeline already shut down. V11-02 replaces this attempt as the current evidence.
