ownership, and shutdown flushes the exact trace and metric pipelines it created.

## Expected Result

Result-returning initialization never panics; initialized pipelines remain live;
the caller owns an idempotent guard that flushes both exact providers.

## Result

- Exit code: 0

- Summary: both subscriber branches call `.init()`, whose dependency contract
  panics when a global subscriber/logger is already set. The tracing layer's

  global provider because this provider was never installed globally or returned.
  The local SdkMeterProvider is not retained: its last handle drops at the end of
  `init_metrics`, and the SDK Drop contract immediately shuts its pipelines down,
  leaving OnceLock Metrics instruments backed by a shut-down pipeline. Metrics
  init errors are flattened to overall success, and EKO discards the facade Result.
