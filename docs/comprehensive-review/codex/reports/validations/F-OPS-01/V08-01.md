under concurrent producers and surface missing/corrupt durable state.

## Expected Result

missing/corrupt state and write loss return errors; cache cannot hide external updates.

## Result

- Exit code: 0
- Duration: static interleaving/state proof
- Summary: append is load/clone/push/save with locks released between operations,

  snapshot and even regress a terminal status. Separate store instances have
  independent caches and unsynchronized two-write file appends. Missing runs and
  unreadable/malformed last lines become successful absence, while cache-first
  reads hide other writers. Live record/finalize callers often discard errors.
