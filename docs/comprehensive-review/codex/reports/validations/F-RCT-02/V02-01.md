## Claim

The non-streaming wrapper returns a typed terminal outcome for every core-loop exit.

## Method

Trace the spawn/collector in `run_react_loop`, every `run_core_loop` early return, and cancellation/abandonment paths in tool execution. Search all producers of `AgentEvent::Cancelled` in the React path.

```text
nl -ba src/agent/react/run/react_loop.rs | sed -n '598,752p'
nl -ba src/agent/react/run/stream_channel.rs | sed -n '494,755p'

rg -n 'AgentEvent::Cancelled|IterOutcome::Abandoned|return Ok\(\(\)\)' src/agent/react/run
```

## Expected Result

Success requires one explicit successful terminal; cancellation and core errors cannot become an empty successful response.

## Result

- Exit code: 0
- Duration: under 1 second per inspection
- Summary: the wrapper discards the spawned task's result, initializes `answer` to empty, and returns `Ok(answer)` when the channel closes. Tool cancellation returns `Abandoned`; the driver converts it to `Ok(())` without producing `AgentEvent::Cancelled`. Other `?` failures are only logged by the spawn wrapper unless a phase separately sent an error.
- Log/artifact: `src/agent/react/run/react_loop.rs:711-750`, `src/agent/react/run/stream_channel.rs:592-609`, `:748-750`, `src/agent/react/run/phases/tools.rs:194-205`, `:295-312`, `:418-422`
