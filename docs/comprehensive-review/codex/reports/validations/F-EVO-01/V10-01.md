## Claim

Skill patch and merge mutators bind reviewed proposals to current source, persist
the authoritative result, surface lifecycle failure, and remain recoverable under
concurrency or audit failure.

## Method

```text
Trace SkillPatcher analyze/proposal/apply and SkillSimilarityDetector proposal/
SkillMerger execute through source descriptor, temp file, Store, Curator and
ChangeLog. Trace live EKO CLI apply/merge callers and search all uses of
EvolutionSecurityGuard::check_skill_patch.
```

## Expected Result

Proposal carries a source revision/hash; apply rejects stale content; one writer
owns the target; primary content and secondary lifecycle persist atomically; every
error accurately reports terminal state.

## Result

- Exit code: 0
- Duration: static inspection
- Summary: invariant failed. SkillPatcher rereads current content but proposals
