## Claim

the consumer root, and commit file/lifecycle/audit state consistently.

## Method

```text
Trace memory groups -> SkillCandidate::from_group/sanitize_name -> candidate Store
and Curator -> generate/generate_from_candidate -> draft path/write -> Curator ->
ChangeLog. Inspect malformed direct candidates, collisions, bounded scan ordering,
serialization/read failures and EKO supplied/default curator paths.
```

## Expected Result

read failures do not become absence; draft file, lifecycle, and audit succeed or
roll back as one explicit operation.
