## Claim

Reviewed memory merge proposals reject stale source and either commit all members
with audit or restore all members automatically on failure, without overflow.

## Method

```text
Trace MemoryReviewer proposal snapshots -> MemoryLayerManager::apply_merge_proposal
stale checks -> MemoryMerger primary/secondary Store writes and ChangeLog records ->
AppliedMemoryMerge snapshots -> restore_merge_snapshots. Compare only this
evolution transaction boundary with accepted F-MEM-01.
```

## Expected Result

Stale proposals fail before mutation; any post-first-write error compensates
automatically; revision aggregation is checked/saturating; restore is itself
all-or-nothing.

## Result

- Exit code: 0

  (`layer.rs:563-651`). However `MemoryMerger` writes the primary, audits it, then
  updates/audits secondaries sequentially (`review.rs:417-480`); any Store or log
  error leaves a partial merge and `apply_merge_proposal` does not automatically
  restore its already-built snapshots. Restore is also sequential and audit can

  `sum::<u32>()` (`review.rs:417-426`).
