## Claim

Boot recovery must move a run left `Running` by a crash to `Paused`, requeue
in-flight replay-safe tasks to `Pending` with their claims cleared, preserve
completed tasks' terminal state, and never implicitly re-execute completed
work after resume.

## Method

Standalone probe (`/tmp/qflt02-probe/src/bin/s6_restart_recovery.rs`): run +
plan (t1, t2), transition Running, claim t1 (in-flight at crash), claim and
complete t2 (durable result at crash), drop the store (crash), open a FRESH
store over the same shadow root (restart), `recover_incomplete()`, snapshot,
re-claim t2 (must NOT be Claimed), re-claim t1 (must be Claimed), resume.

Static side: `recover_incomplete` (`store.rs:1631-1776`) — only `Running`
runs; Running tasks -> Pending (replay-safe) or Blocked + `RecoveryBlocked`
(non-replay-safe boundaries) via `set_task_status` (claim cleared); the ready
frontier (`runtime.rs:449-455`) skips Completed tasks.

## Expected Result

claim cleared; t2 stays Completed; resume works; t2 is never re-dispatched.
