## Claim

A failed review must produce a claim-guarded retry (no unclaimed window, no
terminal regression), fix tasks must preserve the task id and dependencies so
downstream `depends_on` still resolves, the circuit breaker must suspend on
retry-budget exhaustion and repeated failure fingerprints, and acceptance
passes only through the current claim.

## Method

Standalone probe (`/tmp/qflt02-probe/src/bin/s8_review.rs`) driving the REAL
`requires_review` / `circuit_breaker_action` / `build_fix_task`
(`echo-agent-cli/echo-agent-app-core/src/tasks/task_runtime/review.rs:49-276`)
and the REAL store claim/requeue loop: claim -> review NeedsFix (fp-A) ->
`CreateFix` + `build_fix_task` -> `requeue_claimed_task` (retry_count 1,
claim cleared) -> stale attempt completion -> `Superseded` -> re-claim (attempt
2) -> second NeedsFix with same fp -> `Suspend`; retry budget exhausted ->
`Suspend`; pass review -> completion `Applied` (attempt 2) -> Completed.

Static side: `run_review_gate` (`executor.rs:1773-1836`) — `Blocked` review
outcomes short-circuit to `Suspend("review returned blocked")` BEFORE the
breaker (the breaker is only consulted for `NeedsFix`); `resolve_dispatch`
retry budget `claim.attempt-1 < task.max_retries` (`executor.rs:1396-1431`);
every branch writes claim-guarded (`set_claimed_status`/`requeue`/`Superseded`).

## Expected Result

Retries are claim-guarded and budget-bounded; repeated fingerprints suspend;
fix tasks preserve id/deps; acceptance completes via the current claim only.

## Deviations

STEP4's "blocked review -> CreateFix" is an artifact of calling
`circuit_breaker_action` alone: the breaker never inspects `review.outcome`,
but in the real flow `run_review_gate` handles `ReviewOutcome::Blocked`
before the breaker (`executor.rs:1834-1835`), so no behavior defect exists —
recorded as an observation, not a finding. The reviewer-LLM prompt path
(`review_task` with a real `LlmClient`) was not exercised (no LLM in the
probe); the gate's review-input equivalence after restart is already covered by
A-TSK-06 V04-04.
