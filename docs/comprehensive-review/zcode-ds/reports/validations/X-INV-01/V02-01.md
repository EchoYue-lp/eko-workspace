## Claim

`echo-agent-cli` (EKO) has zero SQLite dependencies in its resolved
dependency tree and zero SQLite enablement in source; all `sqlite` grep
matches in the CLI tree are documentation references or comments. The
framework's `sqlite` feature (`echo-agent`/`echo-state`) is a legitimate
independent framework option and is not enabled by the CLI.

## Method

```text
cd /Users/ls/MyWork/code/ylp_agent_learn/lp-agent/echo-agent-cli
# 1. source-code grep (non-doc file types)
grep -rni "sqlite" --include="*.rs" --include="*.toml" --include="*.ts" \
  --include="*.tsx" --include="*.js" --include="*.html" --include="*.json" .

grep -n -i "sqlite\|rusqlite\|libsqlite" Cargo.toml \
  echo-agent-app-core/Cargo.toml echo-agent-eval/Cargo.toml
# 3. resolved dependency tree (normal + build + dev)
cargo tree --locked -e normal,build,dev | grep -i sqlite
# 4. lockfile check
grep -c "name = \"rusqlite\"\|name = \"libsqlite3-sys\"" Cargo.lock
```
