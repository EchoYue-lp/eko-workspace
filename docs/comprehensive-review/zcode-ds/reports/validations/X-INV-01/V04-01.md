## Claim

All `unwrap()`/`expect()`/`panic!`/`unreachable!` occurrences and direct
indexing in both repositories sit in test code, doc comments, or guarded
production code; no live production path panics on abnormal input via
these constructs. (Full unguarded inventory is Q-STA-01's scope; this
audit classifies the complete macro set plus a sampled direct-index set,
focused on live paths.)
