## Claim

Neither repository defines or registers a parallel task-authoring CRUD
surface: `todo_write`, `TodoWriteTool`, `plan_create`, `plan_patch`,
`plan_execute`, `PlanCreateTool`, `PlanPatchTool`, `PlanExecuteTool`,
`search_todo`, `find_todo`, or any global todo store. The only
`task_*`-family authoring API is the framework `task_create`/`task_update`/
`task_list` (plus EKO `task_execute`), per AGENTS.md's single-task-relation
API rule.
