- Owner-conflicting writers never run in the same wave; per-file locks serialize remaining overlap; cross-run isolation via worktrees + merge preflight.
- User uncommitted/staged changes in the main checkout never enter a merge and never get overwritten; cleanup never deletes changed content.

- Merge failure preserves the isolated work and aborts cleanly; cancellation is observed at integration boundaries; integration is idempotent (execution trailer).
