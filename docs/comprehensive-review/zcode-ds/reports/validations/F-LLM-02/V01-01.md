## Claim

The OpenAI adapter maps every `ChatRequest` field to the OpenAI request body faithfully — no field lost, renamed, or hardcoded in a way that violates the neutral contract (`echo_core::llm::types::ChatCompletionRequest`).

## Method

Static field-by-field comparison between the neutral contract (`echo-core/src/llm/mod.rs:148-183` `ChatRequest`), the wire type (`echo-core/src/llm/types.rs:520-573` `ChatCompletionRequest`), and the three request-assembly sites in the OpenAI adapter (`echo-integration/src/providers/openai.rs`: standalone `chat` :139-171, `stream_chat` :175-208, `LlmClient::chat` :264-320, `LlmClient::chat_stream` :322-379) plus `DefaultLlmClient` (:401-514). Hardcoded values flagged separately.
