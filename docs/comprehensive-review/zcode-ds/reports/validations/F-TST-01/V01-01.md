## Claim

There is exactly one framework testing/mock infrastructure (`echo-agent/src/testing`
behind the `testing` feature), with no parallel mock implementations of the same
concept across `echo-agent` or `echo-agent-cli` — except documented local
`#[cfg(test)]` closures and one duplicated `MockEmbedder`.

## Method

Repository-wide grep over both source trees (working dir
`/Users/ls/MyWork/code/ylp_agent_learn/lp-agent`):

```text
1. find . -type d -name testing (echo-agent)
2. grep -rn 'feature = "testing"' echo-agent/src echo-agent/echo-*/src
3. grep -rn "mod testing" echo-agent echo-agent-cli
4. grep -rln "MockLlmClient|MockTool|MockAgent|MockEmbedder" echo-agent echo-agent-cli
5. grep -rn "struct Mock|struct Fake|struct Stub" echo-core echo-integration echo-state echo-execution echo-tools
6. grep -rn "impl LlmClient for|impl Agent for|impl Embedder for" (all crates)
7. find echo-integration -name "*.json" -o -name "*fixture*" (wire fixtures)
8. diff of echo-state MockEmbedder vs src/testing/mock_embedder.rs bodies
```

## Expected Result

One `src/testing` module; `testing = []` empty feature; at most one mock per
concept; any second implementation is a local `#[cfg(test)]` closure or an
intentional, documented test double.
