## Claim

Every disk/cache growth point — JsonlRunStore, TaskRuntime events.jsonl,
trace archives, artifacts, logs, frontend caches — is classified as bounded
or unbounded with anchors, real measurements where available, and canonical
IDs for already-archived findings (F-OPS-01-P2-02, A-TSK-06-P3-02,
X-STA-01-P1-01, A-TSK-05-P2-02, A-TSK-01-P1-01, F-MEM-01-P1-01).

## Method

```text
1. Measure ~/.eko/runs/*.jsonl sizes/line growth (python3) and
   ~/.eko/tasks/*/events.jsonl line composition (largest event line).
2. Trace each persistent store's write path and retention:
   trace/mod.rs (JsonlRunStore), file_shadow.rs (events.jsonl + plan.json +
   run-state.json), ledger.rs (progress.md + artifacts/traces/*.txt),
   state/file.rs (checkpoints), echo-core/src/tools/artifact.rs (30-day
   cleanup trigger), conversation_file.rs / file_conversation.rs,
   frontend stores (MAX_* caps).
3. Grep for deletion/retention entry points: delete, cleanup, prune,
   retention, remove_dir_all.
```

A per-store table: store, growth shape, bound (if any), canonical ID or new
