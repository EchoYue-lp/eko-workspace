## Claim

(a) Every durable semantic mutation on the EKO evolution surface is gated by
an explicit user action or by the documented deterministic-maintenance
exception; (b) dead/aspirational evolution paths are identifiable and
classified; (c) product documentation matches the implemented evolution
surface.

## Method

Static invariant inspection: for each reachable mutation trigger from V02-01,
read the write path and record whether a user action precedes it and whether
the write goes through the audited+security-scanned layer-manager path.
