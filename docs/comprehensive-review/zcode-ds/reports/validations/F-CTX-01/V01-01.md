## Claim

Context selection, budget accounting, and protected-content machinery have a
single authoritative implementation per semantic across `echo-agent` and
`echo-agent-cli`, or every parallel implementation is identified and its
reachability classified (definition / registration / live main path).

## Method

Repository-wide grep across `echo-agent/src`, `echo-agent/echo-core/src`,
`echo-agent/echo-state/src`, `echo-agent-cli/echo-agent-app-core/src` (excluding
`target/` and `tests/`) for the following names and concepts:

```text
ContextAssembler  ContextSelector  ContextManager  TokenBudget
TokenBudgetConfig  ContextBudget  HeuristicTokenizer  SimpleTokenizer
CalibratedTokenizer  TokenUsageTracker  estimate_tokens  count_tokens
add_protected_marker  protected_marker  PreModelContextProjector
ContextProjection  CanonicalContext  reinject_canonical_context
PromptAssembler  max_tool_output_tokens  infer_context_window
```

Every hit group was then classified by reading the defining file and tracing
non-definition references to determine whether the symbol is on a live runtime
path, a public-but-off-path API, or dead.

## Expected Result

Either one authority per concept, or a documented classification showing which
parallel implementation is live, which is an off-path public option, and which
is dead.

## Result

- Exit code: not-applicable (static inspection)
- Summary:
  - Live single authority for the runtime message buffer, budget, and
    compression: `ContextManager` + `echo_core::budget::TokenBudget` +
    `echo_core::tokenizer` (`HeuristicTokenizer`/`CalibratedTokenizer`).
  - Parallel framework building block NOT on the main path:
    `ContextAssembler` + `ContextSelector` (`echo-agent/src/context/`). Doc at
    `src/context/mod.rs:109-117` states the default ReactAgent path does not use
    it. Only references: `examples/demo65_context_assembler.rs`,
    `examples/demo66_context_selector.rs`, and a docstring in
    `src/runner.rs:7` (deprecated `AgentRunner`). `ContextBudget.total_tokens`
    and `user_reserve` are never read in `assemble()` (set-only dead fields).
  - EKO `PromptAssembler` (`echo-agent-cli/echo-agent-app-core/src/project/prompt.rs`)
    is a system-prompt module composer with its own token budget; feeds only
    `ReactAgentBuilder::system_prompt(...)` / a projection — it does not build
    the runtime message list. Different responsibility, not a duplicate of
    `ContextManager`; budget model overlaps with `TokenBudget` percentages.
  - Protected content: `add_protected_marker` / `add_replaceable_protected_marker`
    registered only in `echo-agent-cli/echo-agent-app-core/src/tasks/task_runtime/compact_context.rs:159`
    (EKO task brief) and in a framework test (`echo-state/src/compression/invariants.rs:224`).
    Framework runtime path protects content via projection envelopes
    (`is_context_projection_message`) and `CanonicalContext` re-injection
    instead of markers.
  - `max_tool_output_tokens` split between framework (`AgentConfig`,
    `snapshot.rs` spill policy) and EKO (`infra.rs:34` `resolved_max_tool_output_tokens`);
    single enforcement point (`snapshot.rs:922-1049`).
  - Window mapping: one `infer_context_window`
    (`echo-core/src/llm/capabilities.rs:197-217`), consumed at
    `echo-agent/src/config.rs:99-104` (framework YAML path) and
    `echo-agent-cli/.../model_config.rs:153-159` (EKO GUI model view); NOT
    consumed by the framework builder path or the EKO runtime construction.
- Log/artifact: none
