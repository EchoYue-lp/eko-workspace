## Claim

The full registration -> execution path for a dynamic plan run is
reachable: tool registration (GUI/TUI/CLI/background) -> `execute_run`
drain -> `execute_runtime_plan` -> `RuntimeDagExecutor::execute` ->
`EkoRuntimeDagController` -> `RealTaskDispatcher::dispatch` ->
`execute_task` (subagent delegation with child cancel token).

and EKO as thin controller/dispatcher; cancellation token flows from the
run driver into the per-task subagent dispatch.
