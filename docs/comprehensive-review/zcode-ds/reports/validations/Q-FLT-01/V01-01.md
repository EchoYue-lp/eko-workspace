## Deviations

- (a) SURVIVES with a designed recovery path: the call is dropped and a
  Chinese-language fallback assistant note "(流式工具调用参数解析失败,已跳过;请重新发起工具调用)"

  The drop is warn-logged (processor.rs:165-178). No ToolError event reaches

- (b) SURVIVES: typed `Err(NoResponse)` terminal (finalize.rs:226), trace
