## Deviations

All deviations above are documentation/API-contract mismatches; none
affects compilation of the library itself (phantom features only break
consumers who enable them: `cargo add echo-agent --features plan-execute`
fails with "the package does not have feature `plan-execute`"). The root
`cargo check -p echo_agent --no-default-features` and workspace
no-default-features checks compile clean (V01), so the prelude itself is
internally consistent.

## Conclusion

The V04 claim fails in detail but with a clear pattern: the README (root
and echo-core) documents a pre-workspace-split / pre-M13 API surface
(plan-execute/self-reflection features, `execute_with_planning`,
`TypedTool`, `SubAgent`, echo_core prelude), while the current manifest and
facade are newer. Consolidated into F-API-01-P2-01 (README phantom
features/APIs), F-API-01-P3-01 (macros-not-in-prelude guidance), and
F-API-01-P3-04 (`Error` naming). The docs.rs metadata gap and the 6 no-op
