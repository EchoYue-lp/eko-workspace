## Result

  not executed by `cargo test --doc`; static resolution holds.

  the root facade (root `tools/mod.rs:109-113` list omits it; prelude has no

- Example declarations: 13 of 68 `examples/*.rs` files have no `[[example]]`
  block: demo00_quickstart, demo01_tools, demo02_tasks, demo07_skills,
  demo09_file_shell, demo10_streaming, demo11_callbacks,

  stream_chat}`, `retry`, `error::{Result, ToolError, ReactError}`,

  example files.
- echo-macros derive doctest references the unexported `ToolRunner`.
