## Expected Result

- edit_file: exact-match anchor, ambiguous-occurrence rejection,
  replace_all flag, dry_run, checkpoint + .bak before mutation.
- update_file: anchor-missing rejection; single first-occurrence replace.
- write_file: expected_hash optimistic concurrency; PartialSideEffect +
  idempotency key on failure.
- git tools: `--` before user paths, `-` prefix rejection for diff target,
  argv-array execution (no shell).
- Diff application itself: only string-replace primitives exist; no
  unified-diff parser that could half-apply a patch.
