## Claim

The `web-frontend` package tree is internally consistent (`npm ls` clean), its
duplicate/stale/dead dependency inventory is enumerated, and its advisory
posture is known from a real registry audit (or the audit failure is recorded
with its environmental cause).

## Method

```text
cd echo-agent-cli/web-frontend
npm ls --all > /tmp/qdep-v02-npm-ls.txt            # exit 0
python3 package-lock.json parse                     # version-split enumeration
npm audit --json                                    # failed: registry.npmmirror.com 404 [NOT_IMPLEMENTED]
npm audit --registry=https://registry.npmjs.org --json > /tmp/qdep-v02-npm-audit2.json   # exit 1 (vulns found)
npm outdated --registry=https://registry.npmjs.org
npm ls dompurify vite postcss nanoid @babel/core    # installed versions of advisory hits
grep -rni "dompurify" src/ public/                  # import search
du -sh node_modules dist
```

Environment: node v22.19.0, npm 11.6.0; npm registry configured to
`https://registry.npmmirror.com` (mirror); the official
`https://registry.npmjs.org` was reachable and used for audit/outdated.

## Expected Result

A valid tree, at most minor transitive version splits, and a small set of
patch-level outdated packages. `npm audit` is expected to either report the
true posture or fail for a recorded environmental reason.

## Deviations

- `npm audit` against the configured registry (npmmirror) is impossible (404
  NOT_IMPLEMENTED); the official registry audit is used instead and is the
  source of the advisory data above. The `npm outdated`/`audit` results depend
  on npmjs metadata at review time (2026-08-12).
- `dist/` (3.1 MB) may be a prior build artifact; bundle content was not
  regenerated during this read-only review.

## Conclusion

The frontend tree is internally consistent with one benign transitive split.
The material inventory findings: (1) `dompurify` — a production dependency
with five known advisories fixed only in 3.4.13 — is completely unused
(dead dependency; either remove it and `@types/dompurify`, or upgrade and
wire it deliberately); (2) the build-toolchain advisories (vite/postcss/
nanoid/@babel, all dev-only, fixes available as patch bumps); (3) the
duplicate `@tailwindcss/vite` declaration. These feed findings
Q-DEP-01-P3-01 (dompurify dead+advisory), Q-DEP-01-P3-02 (toolchain
advisories), Q-DEP-01-P3-03 (manifest hygiene). It does not prove runtime
XSS safety of rendered LLM output — that is a behavior claim outside this
inventory.
