## Claim

Webhook/observability/logging concepts have exactly one authoritative definition
per concept across both repositories; no parallel implementation (second
emitter, second observer, second diagnostics writer hiding behind another name)
exists; the removed global emitter is gone.

## Method

`echo-agent-app-core/src/`) and `echo-agent` framework crates, excluding
`target/`:

```text

grep -rni "webhook" echo-agent/src echo-agent/echo-core echo-agent/echo-orchestration echo-agent/echo-state echo-agent/echo-tools
```

the application; no framework-side outgoing webhook emitter (framework owns only
config + the inbound `WebhookHumanLoopProvider`); zero `init_global` /
`emit_global` / `global_emitter` references except the removal note in the
emitter doc comment; one diagnostics consumer path; one application-side trace
terminal writer (`save_trace`) distinct from the framework trace lifecycle.
