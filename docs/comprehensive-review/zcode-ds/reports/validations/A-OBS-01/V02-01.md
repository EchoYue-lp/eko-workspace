## Claim

Every webhook emitter, observer, diagnostics writer, and GUI observability
surface is registered and reachable from a live entry point, and every emitter
delivers to a configured endpoint set; the reachability graph is complete with
no dead producers and no orphan consumers.

## Method

Static call-graph tracing (inspection procedure):

```text
1. Emitter construction: grep WebhookEmitter::from_config / new / with_endpoints in
   src/main.rs, src/tauri/desktop.rs, echo-agent-app-core/src/state.rs.
2. Injection: trace the emitter Arc into AppState.webhook.emitter, TuiApp.webhook_emitter,
   ReplConfig.webhook_emitter, channel runner, scheduler fire_fn, config watcher.
3. Observer: verify WebhookTurnObserver is instantiated inside drive_chat_inner and
   observe()/finish() are reached on the envelope stream; verify cron/background
   paths (launch_cron_run / launch_unattended_run) do NOT instantiate it.
4. Diagnostics: verify list_diagnostic_runs / load_run_diagnostics read the primary
   agent's RunStore (panels.rs:1137-1143) and that TUI /trace uses the same app-core
   functions; check the frontend consumers (api/endpoints.ts, ObservabilityPanel.tsx).
5. Trace record producers: confirm task runs create a framework Run via
   execute_stream_with_invocation_context -> run_stream_entry -> start_scoped_trace_run
   (react/mod.rs, stream_channel.rs:100-109) AND an EKO save_trace terminal record
   (executor.rs:449/491/509/562), and that save_trace sets parent_run_id: None.
6. Scheduler: verify new_scheduler_runner receives the emitter (main.rs:264,
   modes.rs:32-88, desktop.rs:169) and build_fire_fn emits CronTaskCompleted only on Ok.
```

## Expected Result

All surfaces (TUI/CLI REPL/channel/GUI) reach the same per-process emitter;
scheduler and config watcher share it; every task-run terminal writes two trace
records into the same RunStore (framework + save_trace); cron/background paths
have no WebhookTurnObserver; GUI panels consume the diagnostics commands.
