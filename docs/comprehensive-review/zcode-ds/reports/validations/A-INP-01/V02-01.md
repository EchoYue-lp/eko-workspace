## Claim

Every live user-input surface reaches the single `PreparedUserTurn::build`
normalization and the single `drive_chat` / `steer_input` consumption, and the
cleanup helpers are reachable from the surfaces that can delete a conversation
— with no dead or unregistered normalization path.

## Method

Static call-graph trace from each entry-point adapter to `PreparedUserTurn`
and on to the framework; plus registration/reachability grep for
`drive_chat`, `steer_input`, `cleanup_user_input_scope`,
`resolve_user_input_spill_dir`, `inline_attachment_refs`.

```text
cd echo-agent-cli && grep -rn "PreparedUserTurn::build" --include="*.rs" src echo-agent-app-core | grep -v target
grep -rn "drive_chat(" --include="*.rs" src echo-agent-app-core | grep -v target
grep -rn "steer_input" --include="*.rs" src | grep -v target
grep -rn "cleanup_user_input_scope|resolve_user_input_spill_dir" --include="*.rs" src echo-agent-app-core | grep -v target
```

## Expected Result

All five entry surfaces (GUI, TUI, CLI REPL, IM channel, steer) normalize
exactly once before the turn reaches the framework; cleanup runs on the
surfaces that offer conversation deletion.
