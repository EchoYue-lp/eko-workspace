## Claim

Each config/provider/workspace capability is registered and reachable from a
live product path (or is demonstrably dead), and the workspace switch /
hot-reload lifecycle is wired coherently across entry points.

## Method

Static call-graph tracing from each entry point (main.rs TUI/CLI/channels,
desktop.rs GUI, frontend) through config loading, watcher spawn, provider
commands, workspace commands, and switch/exit state replacement.

```text
1. Entry config load: main.rs:100, desktop.rs:133 → config::load_config
2. Watcher: main.rs:232, desktop.rs:166 → spawn_config_watcher (boot only)
3. Provider selection: GUI providers.rs (IPC), TUI /model (tui/events.rs:2690-2730),
   REPL /model (cli/cmd_impls/context.rs:53-64)
4. Workspace: GUI LeftSidebar → workspaceStore.switchTo → workspaceApi.switch
   (endpoints.ts:1422) → tauri switch_workspace (workspace.rs:131) →
   AppState::switch_workspace (state.rs:844); REPL /workspace
   (cli/cmd_impls/workspace.rs:114); TUI: no workspace surface (grep
   tui/*.rs)
5. exit_workspace callers: only delete_workspace (workspace.rs:110-114);
   frontend workspaceStore.exit (workspaceStore.ts:105) has zero callers
6. discover_config frontend callers: zero (grep web-frontend/src)
```

## Expected Result

Workspace switch changes all workspace-scoped state and keeps cwd-derived
resolution (config, hooks, watcher targets) consistent with the active
workspace; exit restores the pre-workspace scope.

## Result

- Exit code: not-applicable (static trace)
- Summary:
  - Config load: single entry per surface (headless main.rs:100, GUI
    desktop.rs:133); GUI ignores `--config` via fixed argv
    (desktop.rs:132).
  - Watcher: spawned once at boot on headless and GUI; never restarted on
    workspace switch; targets fixed at spawn (config_watcher.rs:199-211):
    explicit config path + `~/.eko/hooks.yaml` + `cwd/.eko/hooks.yaml` where
    cwd is captured at spawn.
  - switch_workspace (state.rs:844-1032) mutates: `workspace.current`,
    process CWD via `std::env::set_current_dir` (:854), agent working_dir,
    tool-output artifacts, dynamic-context projections (:883), persistence
    (:894-900), conversation store (:905-935), runtime state store
    (:921-934), memory store + layer manager + curator + skills
    (:945-1020), pool working dir / memory store (:889, :1012-1014), and
    workspace routing (:1029). Does NOT touch: AppConfig (model/provider),
    hook registry, config watcher targets, or TaskRuntimeStore.
  - exit_workspace (state.rs:1053-1185) resets persistence/conversation/
    runtime-state/memory stores and routing to General, but never restores
    process CWD and never reloads config/hooks.
  - Provider switching live paths: GUI providers.rs `set_default_model` /
    `upsert_configured_model` (IPC), TUI `/model` (tui/events.rs:2690-2730,
    real switch incl. pool.apply_runtime_model :2728), REPL `/model`
    (context.rs:53-64, print-only stub). CLI has no provider/model command
    other than the REPL stub.
  - Workspace switching surfaces: GUI only (LeftSidebar switchTo →
    IPC). REPL `/workspace switch` (workspace.rs:114-146) is print-only and
    does not call `switch_workspace`. TUI has no workspace command/UI.
  - `discover_config` IPC registered (tauri/mod.rs:99) but zero frontend
    callers — dead surface.
- Log/artifact: none
