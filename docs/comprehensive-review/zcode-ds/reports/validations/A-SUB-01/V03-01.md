wired and effective; (b) prompt cardinality/language is single-owned per
surface; (c) definition reload exists or is explicitly documented as
rebuild-only, and pooled-Agent refresh is coherent; (d) plugin-registered

## Expected Result

- (a) Every `(profile, kind)` default route exists in the effective catalog
  at every agent build; failure aborts creation.
- (b) EKO compiler emits each shared section exactly once; the language
  anchor and result contract are present; the primary-side invocation
  appends them exactly once and the primary system prompt does not duplicate
  them.
- (c) `.md` edits require a rebuild (documented in module docs); workspace
  switch does not re-discover; new pooled agents re-discover, existing ones
  keep stale registries.
- (d) Plugin subagents use the same EKO compiler as `.md` subagents.
