## Claim

When the external document converter (Pandoc/Quarto) or the PDF engine is
missing, every surface receives an error that retains the cause and names the
missing prerequisite — no silent success and no empty artifact.

## Method

Static trace of the missing-converter paths in
`echo-agent-cli/echo-agent-app-core/src/research.rs`:

1. `resolve_document_renderer` (`:1215-1233`) — EKO_PANDOC, PATH pandoc,
   EKO_QUARTO, PATH quarto; each via `executable_available` (`:1241-1249`).
2. `render_review_document` (`:1251-1259`) — renderer absent ->
   `ResearchError::External("PDF/DOCX export requires Pandoc or Quarto on
   PATH; EKO_PANDOC/EKO_QUARTO may point to a custom executable")`.
3. Pandoc without engine -> `ResearchError::External("Pandoc PDF export
   requires typst, weasyprint, wkhtmltopdf, xelatex, lualatex, or pdflatex;
   EKO_PDF_ENGINE may select another supported engine")` (`:1285-1290`).
4. Renderer non-zero exit -> status + stderr (char-capped 2_000) embedded in
   the error (`:1312-1322`).
5. Surface mapping: Tauri `ipc_error` (`src/tauri/commands/research.rs:28-38`)
   keeps the message via `IpcError::Internal(error.to_string())`; CLI prints
   "Unable to export review: {error}" (`cmd_impls/research.rs:268-274`); agent
   tool returns `ToolResult::error(error.to_string())` (`research_tool.rs:189`).
6. Availability gating: `document_renderer_available` / `pdf_renderer_available`
   (`:1194-1204`) and `export_all_review_formats` (`:1171-1191`) exclude
   unavailable formats; the always-available formats (Markdown/Json/Csv/Bibtex/
   Ris) export unconditionally.

## Expected Result

Errors carry the cause and remediation hint; no fabricated success; the
five renderer-independent formats remain available.

## Result

- Exit code: not applicable (static; the pandoc fixture test in V04-04
  exercises the happy path)
- Summary: all six steps above verified against source. `ReviewExportFormat`
  export paths return typed `ResearchError::External` with actionable
  messages on every surface; the GUI additionally filters the format list by
  renderer availability; `export_review` for Pdf/Docx never writes a partial
  artifact on converter failure (error raised before `atomic_write`).
