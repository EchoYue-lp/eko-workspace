## Claim

Duplicate crate versions in both lockfiles are enumerated, classified
(direct-controllable vs transitive-ecosystem), and checked for security- or
behavior-significant splits.

## Method

```text
# 1. Parse both Cargo.lock files; group packages by name, flag names with >1
#    version
python3 lockfile-scan   # echo-agent: 38 dup packages; echo-agent-cli: 76
# 2. For the notable splits, trace reverse dependencies:
cargo tree --locked -i <pkg>@<ver>   # in echo-agent-cli workspace
```

## Result

- Exit code: 0
- Summary:
  - **echo-agent (38 multi-version packages)**: mostly ecosystem splits —
    `hashbrown` (4 versions: 0.12.3/0.14.5/0.15.5/0.16.1), `windows-sys`
    (0.48/0.52/0.59/0.60.2), `quick-xml` (4 versions), `rand` (0.8/0.9/0.10),
    `thiserror` 1+2, `zip` 0.6.6+2.4.2, `indexmap` 1+2, `html5ever` 0.29+0.31,
    `getrandom` 0.2/0.3/0.4. No direct-dependency duplicate in the framework's
    own `[dependencies]`.
  - **echo-agent-cli (76 multi-version packages)** — notable splits with
    reverse trees:
    - **`reqwest` 0.12.28 + 0.13.3**: 0.12 is direct (via `echo-agent`/
      `echo-agent-app-core`); 0.13.3 is locked but has **no reverse path under
      default features** (`cargo tree -i reqwest@0.13.3` returned empty) — a
      lockfile-stale entry or a feature-only path. Two HTTP clients coexist in
      the shipped app (TLS/body semantics differ) → finding Q-STA-01-P3-03.
    - **`crossterm` 0.28.1 + 0.29.0**: 0.28 used directly by the CLI binary,
      `ratatui 0.29.0`, and `reedline 0.38.0` (the TUI input stack); 0.29 only
      via `comfy-table 7.2.2 → polars-core 0.53.0`. Two terminal-emulation
      libraries in one app — both may write raw-mode state; split is
      transitive via polars → finding Q-STA-01-P3-03 (same finding).
    - **`toml` 0.8.2 (via `config 0.14.1`, app-core config) + 0.9.12 (via
      `cargo_toml → tauri-build`, build-dep) + 1.1.2**: config parsing across
      three parser generations.
    - **`thiserror` 1.0.69 + 2.0.18 / `syn` 1.0.109 + 2.0.117**: proc-macro
      ecosystem split (macro crates still on syn 1).
    - **`base64` 0.21.7 (ron→config, swift-rs→tauri) + 0.22.1 (docx-rs)**.
    - **`bincode` 1.3.3 (syntect) + 2.0.1 (polars-utils)**; `zip` 0.6.6+2.4.2;
      `rand` 0.8/0.9/0.10; `bitflags` 1+2; `indexmap` 1+2; `itertools`
      0.12/0.13/0.14.
  - No duplicated crate is a security-sensitive one with a known-advisory
    version split (advisory scan is Q-DEP-01's scope); the splits are
    transitive and mostly unavoidable without version-alignment patches.

## Deviations

`cargo tree -i reqwest@0.13.3` ran under default features; a feature-gated
path may exist (the lockfile resolved it). `cargo tree -i` for all 76 names
was not run (context budget); the notable ones were traced.

## Conclusion

Duplicate versions are widespread but benign in kind: all are transitive
ecosystem splits except the two directly controllable ones (reqwest 0.12/0.13,
crossterm 0.28/0.29 in the CLI). These two are material maintainability/
behavior-surface items → Q-STA-01-P3-03.
