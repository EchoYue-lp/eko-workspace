## Claim

Every Rust source file over ~1500 lines is enumerated and given a split
rationale; the list is finite and dominated by single-authority engine
modules rather than accidental accretion.

## Method

```text
find <repo>/<member-dirs> -name '*.rs' -not -path '*/tests/*' -not -name 'tests.rs' \
  | xargs wc -l | awk '$1 > 1500' | sort -rn
```
