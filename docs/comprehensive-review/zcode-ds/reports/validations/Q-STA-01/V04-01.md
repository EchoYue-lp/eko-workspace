## Claim

No live production path performs arithmetic (subtraction/multiplication/casts)
that can overflow or underflow on input-reachable values; the project's own
pattern (`checked_`/`saturating_`/`wrapping_`/guard-before-subtract) is used
everywhere a bound is not provable from surrounding code.

## Method

```text
# 1. Static scans over production regions, both repos:
#    - `\.len() - X` / `count - X` subtraction sites (checked against their
#      immediate guards)
#    - narrowing casts (`as u8/u16/u32/i32/i64`), `as usize` from signed/float
#    - size multiplications (`i * per_bin`, `keep * 2`, `2u64.pow(...)`)
# 2. Inspect each site's guard (len check / loop bound / config bound)
```

## Expected Result

Every subtraction/cast site has a verifiable guard; residual risk is
config-bounded and below overflow magnitude.
