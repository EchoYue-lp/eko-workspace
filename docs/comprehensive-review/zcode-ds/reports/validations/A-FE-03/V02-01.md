## Claim

Every registered listener/timer/polling loop in the frontend is either cleaned up on unmount or is an intentional app-lifetime singleton; the root assembly mounts each surface exactly once; every stateful surface is reachable from `main.tsx`/`App.tsx`.

## Method

Static trace of registration → cleanup pairs:

```text
1. Root assembly: src/main.tsx → App.tsx (StrictMode) → ErrorBoundary/RequireAuth/AppLayout(LeftSidebar, ChatPanel, RightWorkspace)/SettingsDialog/NewTaskDialog/CommandPalette/ToastContainer/InterruptPromptDialog; verify single mount points and no duplicate dialog mounting.
2. Listener cleanup audit for all 23 timer/listener sites found in V01-01: read each useEffect pair (addEventListener/setInterval/setTimeout vs removeEventListener/clearInterval/clearTimeout), classify cleaned / app-lifetime / leak.
3. Polling lifecycle: taskRuntimeStore.startPolling/stopPolling/reset/loadByConversation (generation guards, refreshInFlight).
4. Dead-surface reachability: TasksPanel, McpManagerPanel, PlanEditor, ResultFullView imports (zero) vs surfaces mounted in App.tsx/RightWorkspace.
```

## Expected Result

Root assembly is flat and single-mounted; all component-scoped listeners return a cleanup; polling stops when the run reaches a terminal status and on reset; dead components have zero importers.
