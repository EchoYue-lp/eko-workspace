## Claim

For large chats and large task runs, rendering is bounded: per-token updates re-render only the streaming message; the message list is windowed or otherwise capped; keyboard/focus/label and responsive (viewport-adaptive) interaction invariants hold in the reviewed components.

## Method

Static invariant inspection over the chat/task render path and a11y/responsive inventory:

```text
1. Large-chat render path: read ChatPanel.tsx (message map, scroll effect), MessageBubble.tsx (memo wrapper, store subscriptions, ActionButton callbacks), ParallelExecutionBlock.tsx (whole-store subscriptions, Set construction), chatStore.ts appendToken/appendThinking (array identity per token), ChatInput.tsx (whole component).
   - Determine per-token re-render fan-out: zustand v5 selector semantics (new `messages` array reference → every `useChatStore(s => s.messages)` subscriber re-renders; React.memo cannot short-circuit subscription-driven re-renders); check whether ChatPanel's onRegenerate/onEditAndResend props are referentially stable across renders.
   - Check MAX_MESSAGES cap (chatStore.ts:104-112) application on all growth paths.
   - Check virtualization: package.json deps and src grep.
2. Keyboard/focus/label smoke: global shortcuts (useKeyboardShortcuts), Escape handling in SettingsDialog/CommandPalette/MessageBubble edit/InterruptPromptDialog (absent), textarea Enter-to-send + palette arrows, autoFocus inputs, icon-only buttons without aria-label/title, role/aria usage inventory (role=log/main/tooltip/tab/switch/dialog), img alt attributes, label htmlFor usage.
3. Responsive smoke: max-md overlay/sidebar (AppLayout), RightWorkspace full-width mobile overlay + viewport-adaptive width (rightWorkspaceStore), ChatPanel max-w-980 container, FileBrowser mobile tree.
```

## Expected Result

Per-token work touches only the streaming message; a cap bounds memory; modals carry dialog semantics with focus management; icon-only buttons have accessible names; responsive breakpoints are present.

## Result

- Summary:
  1. **Large-chat rendering — NOT bounded (A-FE-03-P2-01):**
     - `chatStore.appendToken` (:241-249) and `appendThinking` (:251-267) replace the whole `messages` array on every token (new array reference).
     - Every `MessageBubble` subscribes to the whole array (`MessageBubble.tsx:187` `useChatStore((state) => state.messages)`) and to all subagent runs (:186); every `ParallelExecutionBlock` (rendered inside each bubble, MessageBubble.tsx:371/375) subscribes to the whole array too (ParallelExecutionBlock.tsx:71) and re-builds `lastAssistantMessageId` + `knownMessageIds = new Set(messages.map(...))` per render (:72-84).
