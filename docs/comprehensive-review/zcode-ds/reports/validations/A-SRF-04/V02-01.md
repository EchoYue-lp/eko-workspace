## Claim

Every non-GUI/TUI trigger (CLI REPL, IM channel, cron, background) is
registered at boot and reaches the same core runtime (shared `drive_chat` for
interactive triggers; the TaskRuntime executor path for cron/background), with
the trigger-adapter matrix verified entry point by entry point.

## Expected Result

REPL/channel turns enter `drive_chat` (same driver as TUI/GUI); cron and
background runs enter `drive_agent_run`/`execute_run` (TaskRuntime path);
the channels-only branch lacks the scheduler/background-service assembly that
every other mode performs; the combined `--channels --cli` branch abandons the
channels task.
