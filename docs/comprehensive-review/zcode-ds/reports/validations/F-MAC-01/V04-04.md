## Claim

The macro showcase example builds only with the (no-op) `macros` feature, the
default example build skips it, and ordinary `#[tool]` examples build under
default features — i.e. the attribute macro is exercised by default example
CI while the derive-through-facade path is not.

## Method

Three commands in `/Users/ls/MyWork/code/ylp_agent_learn/lp-agent/echo-agent`:

```text
cargo check --example demo25_macros --features macros --locked   # showcase, with feature
cargo check --example demo25_macros --locked                     # showcase, default features
cargo check --example demo01_tools --locked                       # #[tool] example, default features
```

Offline; exit codes recorded.

## Expected Result

- demo25 with `--features macros`: exit 0 (macro showcase compiles).
- demo25 without the feature: exit 1 — cargo refuses with
  "requires the features: `macros`" (because `required-features` is set, even
  though `macros = []` gates nothing).
- demo01_tools: exit 0 (attribute macro exercised in default example builds).

## Result

- Exit codes:
  - `--example demo25_macros --features macros`: **0** (Finished, no errors).
  - `--example demo25_macros` (default): **1** — `error: target demo25_macros
    in package echo_agent requires the features: macros`.
  - `--example demo01_tools` (default): **0**.
- Summary: the `macros` marker feature (`Cargo.toml:100`, no gates) controls
  only example `required-features` (`Cargo.toml:200,301`). Default example
  builds therefore compile the `#[tool]`/`#[callback]`/`#[guard]` attribute
  macros (demo01 etc.) but skip the showcase (demo25) that additionally uses
  `agent!` and could host derive coverage. Since no example uses
  `#[derive(Tool)]`, default CI never compiles the derive through the facade —
  consistent with how P1-01 shipped unnoticed.

## Conclusion

The feature-boundary claim holds: `macros` is a no-op marker whose only effect
is excluding the showcase example from default example builds (and making the
README's `cargo run --example demo25_macros` command fail as written — see
V05-01). The attribute-macro path has default example coverage; the derive
path has none outside echo-tools' echo_core-based usage.
