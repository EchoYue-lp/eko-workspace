## Claim

`TaskSpec + TaskExecution + TaskStatus` (composed `Task`) is the sole
authoritative dynamic task model in the framework and EKO; `PlanSpec`/
`PlanTaskSpec`/`TaskPlan`/`PlanRevision` are authoring/file artifacts,
`TodoItem`/`TodoStatus` are UI projections, and no `todo_write`/
`plan_create`/`plan_patch`/`plan_execute` tool survives anywhere.

## Method

Repository-wide grep (both repos, excluding `target/`) for definitions and
uses of the following names and tool names:

```text
cd /Users/ls/MyWork/code/ylp_agent_learn/lp-agent
grep -rn --include="*.rs" -E "struct (TaskSpec|TaskExecution|TaskStatus|PlanSpec|TodoItem|TodoStatus|PlanTaskSpec|ManagedTask|Task)\b|enum (TaskStatus|TodoStatus|TaskKind)\b" echo-agent echo-agent-cli/echo-agent-app-core echo-agent-cli/src-tauri
grep -rn --include="*.rs" -E "struct (EkoTaskSpec|EkoTaskExecution|TaskPlan|TaskNode|TaskNodeStatus)" ...
grep -rn --include="*.rs" "todo_write|plan_create|plan_patch|plan_execute" ...
grep -rn --include="*.rs" '"task_create"|"task_update"|"task_list"|"todo_write"' ...
grep -rn --include="*.ts" --include="*.tsx" "plan_create|plan_patch|plan_execute|todo_write" echo-agent-cli/web-frontend/src
```

## Expected Result

Exactly one definition per model type; EKO DTOs marked as projections;
framework tool names defined once; no forbidden tool name.
