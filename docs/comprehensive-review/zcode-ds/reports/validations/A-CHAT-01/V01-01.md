## Claim

The shared chat driver (`drive_chat`, `ChatSink`, `ChatDriverEvent`) has exactly
one definition in `echo-agent-cli`, zero definitions in `echo-agent`
(framework), and no parallel chat-driver or chat-event concept in either
repository; the framework's streaming/cancel/terminal concepts used by the
driver have one producer each.

## Method

Repository-wide grep (both repositories, excluding `target/` and
`node_modules/`), with definition vs registration vs live-caller distinction:

```text
# echo-agent (framework)
grep -rn "drive_chat" echo-agent --include="*.rs"
grep -rn "ChatSink\|ChatDriverEvent" echo-agent --include="*.rs"
grep -rn "envelope_event_stream" echo-agent --include="*.rs"
grep -rn "AgentEvent::Cancelled" echo-agent --include="*.rs"
grep -rn "steer_input" echo-agent/src/agent/handle.rs

# echo-agent-cli
grep -rn "drive_chat\|ChatSink\|ChatDriverEvent" echo-agent-cli --include="*.rs"
grep -rn "impl.*ChatSink for" echo-agent-cli --include="*.rs"
grep -rn "envelope_event_stream" echo-agent-cli --include="*.rs"
grep -rn "execute_stream\b\|execute_stream_with_invocation_context\
  \|execute_stream_message_with_invocation_context\|chat_stream" echo-agent-cli --include="*.rs"
grep -rn "ChatEvent::InterruptPrompt\|ChatDriverEvent::Interrupt" echo-agent-cli --include="*.rs"
grep -rni "worker" (chat_driver.rs, tui/events.rs, tauri/commands/chat.rs,
  cli/channels.rs, cli/repl.rs)
```

## Expected Result

One `drive_chat` definition with four production call sites (TUI, GUI, CLI
REPL, channel); three production `ChatSink` implementations (TuiChatSink,
TauriChatSink, ChannelChatSink) plus one test-only MockChatSink; no
`drive_chat`/`ChatSink`/`ChatDriverEvent` in the framework; `AgentEvent::Cancelled`
produced only by the default `cancel_aware_stream` wrapper (which ReactAgent
overrides away, per F-RCT-03-P1-02); no `worker` terminology in the touched
application files.

## Deviations

The `ChatDriverEvent::Interrupt` variant is a defined-and-consumed but never
produced wire event (producer gap); `find_in_progress_run_by_conversation`
interrupt detection is GUI-only. Both are recorded as findings in the task
report (A-CHAT-01-P2-01 and the V03 sink diff).

## Conclusion

Supports: one shared chat driver definition with four live call sites; no
duplicate chat driver in either repository; three production sinks; envelope
as the single raw-stream adapter; no worker terminology. Does not prove: the
sink implementations' behavioral equivalence (V03), or runtime reachability of
each call site (V02).
