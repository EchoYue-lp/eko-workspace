## Claim

Across Claude Code, OpenAI Codex, Cursor, Devin, and Temporal, the
converged patterns are: (1) plans are editable artifacts approved through
permission/prompt gates, not runtime state machines; (2) execution state is
recoverable from an append-only event/rollout record, not from mutable
snapshots alone; (3) side effects are recorded durably and replay-safe;
(4) sandbox and approval policy are separable, typed concepts; (5) review
is a separate agent/phase from writing.

## Method

Synthesis of validation reports V01-V04 (each records source URL, access
date, supported claim, limits). Convergence criterion: a pattern supported
by at least three independent implementations.

## Conclusion

Supports the five converged patterns stated in the Claim. These become the
constraint set for downstream architecture findings: EKO's
`events.jsonl`-as-authority + payload-before-event, typed terminal
`RuntimeEventKind`, plan files as editable artifacts with permission-gated
approval, separate review/acceptance from execution, and sandbox vs
approval policy separation all align with the converged industry model.
EKO's `EkoRuntimeDagController` + `RuntimeDagExecutor` split (framework
kernel + app policy) matches the Codex sandbox/approval separation and
Temporal worker/framework split.

Does not prove: that any single system implements all patterns; the matrix
is the cross-system consensus, used for prioritization, not for
copy-anything.
