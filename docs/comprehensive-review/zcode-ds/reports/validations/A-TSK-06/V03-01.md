## Claim

The four required invariants hold: (a) acceptance/check separation — execution
checks and required artifacts need hard observed evidence while acceptance
criteria are judged only by the reviewer; (b) artifact retention — produced
artifacts survive; (c) bounded parent summaries — parent-facing projections are
bounded and UTF-8 safe; (d) no thinking-protocol leakage into review input or
parent context.

## Expected Result

- (a) `execution_checks` require `SubagentVerificationSource::Observed` +
  Passed evidence; `required_artifacts` require available + 64-char sha256 +
  non-empty producer id; `acceptance_criteria` are never auto-passed and are
  judged only by the reviewer LLM; run completion re-checks Completed tasks.
- (b) Artifacts are retained in `SubagentTaskResult.artifacts` (persisted in
  `SubagentReleased` events and `TaskExecutionSummary`) with hash/producer
  identity; standalone `Artifact`/`ArtifactProduced` records are expected to be
  written at task completion.
- (c) Every parent-facing projection is char-bounded (capsule constants
  MAX_SUMMARY_CHARS=260, 80 chars/item, 3 items/field; framework summary
  DEFAULT_SUMMARY_CHARS=1200, MAX_RESULT_ITEMS=64, MAX_DETAIL_CHARS=500,
  MAX_PATH_CHARS=2048) and UTF-8 safe (`chars().take` everywhere).
- (d) Thinking tokens never enter `output` (both subagent paths route them to
  realtime `ThinkingDelta`/`DispatchThinkingDelta` events), are never
  persisted (only the realtime sink), never reach the review prompt
  (uses `full_output` = non-thinking text), and never enter summaries,
  capsule, memory candidates, or hook events (bounded summary only).
