## Claim

The review gate, the compact-context capsule, the memory bridge, and the
full-result persistence path are registered and reachable from live entry
points (definition -> registration -> live caller), and the review input is
restart-equivalent because the complete Subagent output is persisted on the
terminal boundary and reused after recovery.

## Method

Static call-graph trace with `grep -rn` and targeted reads of each
registration site:

1. Review gate: `reviewer_llm` threading — `src/tauri/commands/task_runtime.rs:238/332`

## Expected Result

Every path above terminates at a live consumer; the persisted
`full_output`/`result` pair is read back verbatim by recovery.

## Result

- Exit code: not applicable (static trace)
- Duration: not applicable
- Summary: all five traces reach live consumers. Registration points verified
  at the cited lines; the `SubagentReleased` event payload carries
  `result` + `full_output` (store.rs:1956-1966) and `recoverable_subagent_result`

- Deviations: `MemoryEvent::ReviewFoundIssue` and `RepeatedTaskFailure` have

  `store.add_artifact` has no reachable caller (finding P2-01).

persistence/reuse paths are registered and live; the two dead arms above are
recorded as findings. Restart-equivalent review input is preserved by design
