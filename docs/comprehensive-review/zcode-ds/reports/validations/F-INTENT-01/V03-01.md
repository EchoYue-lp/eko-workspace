## Claim

The intent subsystem's label/decision contract, timeout/fallback behavior,
explainability, and separation from runtime state authority can be verified by
inspection against its tests and call sites.

## Method

Static invariant/edge-case inspection. Files read in full:
`src/intent/mod.rs`, `src/intent/classifier.rs`, `src/intent/trigger_supervisor.rs`,
`src/agent/react/run/react_loop.rs:598-823`, `src/agent/react/run/stream_channel.rs:1-315`,
`src/agent/react/run/context.rs:430-623`, `src/agent/react/capabilities.rs:940-1029`,
`src/agent/react/mod.rs:215-266,571-629,1489-1492`, EKO `runtime.rs:270-356,594-670`,
`infra.rs:420-450`, `echo-core/src/llm/mod.rs:52-107`, provider
`echo-integration/src/providers/openai.rs` (timeout scan), `echo-core/src/agent/mod.rs:143`
(`AgentEvent` variant scan).

## Expected Result

- Label contract: `Intent` = `DirectAnswer{confidence}` /
  `SkillRequired{skill_name,confidence}` / `Fallback`; threshold applied once
  at the router boundary.
- Fallback on classifier error: LLM classify failure -> `Fallback` (warn log).
- Bounded: classification has a timeout/cancel path or provider bound.
- Explainable: decision observable through typed events or trace.
- State authority: classification and routing never mutate task graph / run
  state machine.

## Result

- Exit code: not-applicable (static inspection)
- Summary:
  - Label contract: coherent. `KeywordClassifier` emits DirectAnswer at fixed
    0.85, SkillRequired with a score formula clamped [0.3, 0.95]; LLM parser
    defaults missing confidence to 0.5 and unknown labels to Fallback; router
    applies `confidence_threshold` (default 0.7) and per-shortcut enable flags.
  - Fallback: `LlmIntentClassifier` maps LLM errors to `Intent::Fallback` with
    a warn (classifier.rs:411-417); `TriggerSupervisor::fuse` returns Fallback
    when all sources are low; guard-block and hook-block paths return terminal
    events without ReAct.
  - Timeout/bounded: NO framework-level timeout, cancel token, retry, or
    circuit breaker on the classification call. `LlmIntentClassifier::classify`
    calls `llm.chat_simple` (classifier.rs:411) which builds a `ChatRequest`
    with `cancel_token: None`; the call is awaited while the agent holds its
    `execution_mutex` (stream_channel.rs:77 -> :181-280; react_loop.rs:600 ->
    :622-682), so a hanging classifier stalls every subsequent turn on the
    agent. Only provider-level bound exists (OpenAI non-streaming request
    timeout 120 s, openai.rs:257; streaming env timeouts).
  - Explainability: no `AgentEvent` variant and no trace `RunEvent` carries the
    intent decision; only `tracing` logs at info/debug. `activate_skill`
    returns `Ok(())` silently for uninstalled skills (capabilities.rs:965-967).
  - State authority separation: holds. The intent module imports only
    `crate::llm::types::Message`; routing side effects are limited to skill
    registry activation (`activate_skill`), pre-model context projections, and
    trace finalization. No task relation graph, revision, or run-state machine
    mutation; EKO chat asserts "ordinary chat must not create a TaskRun"
    (chat_driver.rs:885-894).
  - Duplicate thresholds: `TriggerSupervisor::fuse` hardcodes
    `HIGH_CONFIDENCE = 0.7` (trigger_supervisor.rs:14) independently of
    `IntentRouterConfig.confidence_threshold`; hook-adopted SkillRequired is
    emitted at fixed confidence 0.6 (trigger_supervisor.rs:58), below both the
    default and the EKO-wired threshold 0.7, so the router converts it to
    Fallback (mod.rs:136-150).
  - Hook slot write paths: only the streaming prepare writes the cache
    (context.rs:544-552); the non-streaming prepare (`react_loop.rs:508-591`)
    does not fire the hook at all; the core-loop `prepare_turn`
    (phases/prepare.rs:57-88) fires UserPromptSubmit without writing the cache
    and ignores `activate_skill` (double-fire already reported as
    F-RCT-02-P2-03).
  - Stale-slot edge: guard-blocked turns (stream_channel.rs:141-179) return
    before classification, leaving a written cache slot for the next turn.

## Deviations

Static only; the hook-fusion dead path (0.6 < 0.7) was not executed
dynamically but is a deterministic arithmetic comparison of two constants.

## Conclusion

Supports: label contract and fallback are coherent; separation from runtime
state authority holds; boundedness and explainability have gaps (findings
F-INTENT-01-P1-01, P2-01, P3-01, P3-02); EKO projector/wiring contradiction
(F-INTENT-01-P2-02) verified statically.
