## Claim

EKO browser, MCP, and LSP capabilities are registered and reachable on the
live entry points: boot loads user MCP config into the agent; GUI/TUI/CLI each
have a reachable MCP management surface; the browser runtime is constructed
once, tools are installed on the primary agent and subagents, and shutdown is
wired on every entry point; LSP tools are registered on the primary agent at
boot.

## Expected Result

- Every surface reaches the same agent-level MCP/browser/LSP services.
- CLI `/mcp connect <name>` and `/mcp disconnect <name>` either perform a real
  connection/disconnection or are absent.
- Browser shutdown is invoked on TUI and GUI exit paths.

## Result

- Exit code: not-applicable (static trace)
- Summary:
  - Boot MCP: verified chain, one warning-only failure path
    (infra.rs:1101-1103). `load_mcp_from_file` connects every enabled server
    with skip-on-connect-error (capabilities.rs:1251-1262), but the
    `to_server_configs` validation step is all-or-nothing (see V03-01).
  - GUI: all six commands registered; `connect_mcp_server` runs un-gated by
    permission mode with input validation (see V03-03); `update_mcp_config`
    reconnects in a background task with a 15 s per-server timeout
    (mcp.rs:502-553).
  - TUI: functional `/mcp list|load|disconnect` (events.rs:3434-3450).
  - CLI: `/mcp connect` and `/mcp disconnect` print "Connecting to MCP
    server: {name}" / "Disconnecting: {name}" and return — NO connection or
    disconnection is performed (skills.rs:255-267). Stub confirmed. Task
    report finding P2-01.
  - Browser: constructed once per `AgentRuntime::bootstrap`, shared by all
    surfaces; tools installed on primary + writer + readonly subagents;
    shutdown wired on TUI (3 exit paths) and GUI (desktop.rs:263-267) and in
    `BrowserRuntime::shutdown`/`interrupt` (mod.rs:185-204). Sidecar spawn via
    `npx -y @playwright/mcp@latest` (config.rs:55-68, sidecar.rs:35-61) with
    lazy `ensure_client` retry (mod.rs:232-271) and per-call restart-on-
    retry-safe-failure (mod.rs:867-938).
  - LSP: 5 tools on the primary agent only; subagent builders add no LSP
    tools (grep of `infra.rs`/`agent_pool.rs` for Lsp: zero hits) — task
    report P3-02.
  - Health: `mcp_health` updated every 30 s; healthy = client present and
    `!tools().is_empty()` (state.rs:768-777).
- Log/artifact: none

## Deviations

  (infra.rs:1091) and `LspConfig::discover(project_root)` + `.lsp.yaml`
  walking (runtime.rs:509-557) — the inventory is display-only.
