## Claim

LSP, IM channel, and A2A protocol concepts have exactly one authoritative
definition each across `echo-agent` and `echo-agent-cli`; no parallel
implementation exists in the other repository or crate.

## Method

1. `find` for directories named lsp/channel/a2a in both repositories.
2. `grep -rn "trait MessageHandler|impl MessageHandler"` — MessageHandler
   implementations.
3. `grep -rn "struct InboundMessage|struct OutboundMessage|struct
   ChannelManager"`.
4. `grep -rn "A2AServer|A2AClient"` and `grep -rn "struct LspManager|struct
   StdioLspClient|trait LspClient"`.
5. `grep -rni "worker"` over all files of the three families.
6. Root facade inspection: `src/lib.rs`, `src/channels.rs`, `src/lsp.rs`,
   `echo-integration/src/channels/mod.rs`, `echo-core/src/lsp/mod.rs`,
   `src/a2a/mod.rs`.

## Expected Result

Single definitions; `worker` terminology absent (Subagent-only rule);
facades re-export rather than re-define.

## Result

- LSP: `trait LspClient` only in `echo-core/src/lsp/client.rs:54`; `struct
  StdioLspClient` only in `echo-integration/src/lsp/client.rs:22`; `struct
  LspManager` only in `echo-integration/src/lsp/manager.rs:20`. Root
  `src/lsp.rs` is a pure re-export facade (10 lines).
- Channels: `struct InboundMessage`/`OutboundMessage` only in
  `echo-integration/src/channels/types.rs:74,125`; `trait MessageHandler`
  only at `types.rs:175`; `struct ChannelManager` only at
  `echo-integration/src/channels/manager.rs:16`. Implementations:
  `AgentChannelHandler` (root `src/channels.rs:113`), `SessionHandler`
  (session.rs:342), `QqMessageHandler` (qq/channel.rs:249),
  `FeishuMessageHandler` (feishu/channel.rs:411). EKO's
  `AppChannelMessageHandler` (echo-agent-cli/src/cli/channels.rs:78)
  implements the framework trait, does not define a second message model.
- A2A: `A2AServer` only in `echo-agent/src/a2a/server.rs:35`; `A2AClient`
  only in `src/a2a/client.rs:17`; zero A2A references in echo-agent-cli
  (grep `a2a|A2A` over CLI sources returned only unrelated matches).
- `worker` grep over `echo-integration/src/channels`,
  `echo-integration/src/lsp`, `echo-core/src/lsp`, `src/a2a`,
  `src/channels.rs`, `src/lsp.rs`, `echo-agent-cli/src/cli/channels.rs`:
  all hits are substrings of `NetworkError` — no worker terminology.
- `subagent` appears only in an EKO comment (cli/channels.rs:200), no
  protocol type named after worker/subagent.

## Deviations

`echo-core/src/lsp/mod.rs:11-12` documents tool implementations living in
`echo-tools/src/lsp/`; no such directory exists (tools live in
`echo-agent/src/tools/lsp.rs`). Recorded as V05 doc drift and
F-INT-02-P3-03.

## Conclusion

Supports: single authoritative definitions per protocol family, no parallel
model in the other repository. Does not prove: registration/reachability
(V02) or runtime behavior (V03/V04).
