## Claim

Malformed JSON-RPC requests, unknown methods, hostile bodies, and
malformed SSE input are answered with protocol errors or skipped — no
panic, no process-level risk.

## Method

Static trace of `src/a2a/server.rs` (`handle_request`,
`handle_request_stream`), `src/a2a/serve.rs` (`parse_method`,
`handle_sync`/`handle_sse`, DefaultBodyLimit), `src/a2a/client.rs`
(`parse_sse_data`, UTF-8 handling), and the proptest suite in serve.rs.

## Expected Result

Parse error → JSON-RPC `-32700`; unknown method → `-32601`; body size
bounded; SSE parse failures skipped.

## Result

- `handle_request` (server.rs:81-125): malformed JSON → `-32700`
  (verified by test `test_handle_parse_error`, V04-03); unknown method →
  `-32601`; `tasks/sendSubscribe` via plain `handle_request` → `-32601`
  with a helpful message.
- `parse_method` (serve.rs:296-321) is byte-slice based but guarded; the
  proptest suite (serve.rs:396-458) proves no panic over arbitrary
  Unicode/whitespace/nested input.
- Body size bounded: `DefaultBodyLimit::max(max_body_bytes)` (serve.rs:145,
  default 1 MiB, configurable) — oversized bodies rejected by axum with
  413.
- `handle_request_stream` parse failure → HTTP 500 with JSON error body
  (serve.rs:283-291) — a protocol deviation (a parse error should be a
  200 JSON-RPC `-32700` response), but non-crashing.
- Client SSE parsing: `String::from_utf8` failure → warn + skip
  (client.rs:252-258); `parse_sse_data` returns `None` on malformed data
  (client.rs:371-377) — skipped. UTF-8 slice boundaries in SSE framing
  are at `\n` bytes, always valid boundaries.
- A2A types deserialize strictly but all server paths fall back to
  error responses; `TaskState` unknown-string deserialization fails → the
  request errors out rather than panicking.

## Deviations

SSE parse errors surface as HTTP 500 instead of JSON-RPC parse error
(P3, low impact); CRLF-framed SSE events are not split (finding
F-INT-02-P3-06).

## Conclusion

Supports: no panic on malformed input; bounded bodies; protocol error
responses on the sync path. Minor deviations on the SSE error path.
