## Claim

IM wire concepts (QQ opcodes, Feishu protobuf frame types, platform
message IDs) stay at the channel adapter boundary; internal APIs use the
single `InboundMessage`/`OutboundMessage`/`MessageHandler` model; no
worker terminology.

## Method

1. `grep -rni "worker"` over `echo-integration/src/channels` — only
   `NetworkError` substrings.
2. Inspect wire-boundary modules: `qq/gateway.rs` (OP_* opcodes, INTENT_*
   bitmasks), `feishu/proto.rs` (FRAME_TYPE_*, MESSAGE_TYPE_*),
   `feishu/api.rs` (API constants).
3. Verify EKO bridges through framework types only
   (`echo-agent-cli/src/cli/channels.rs`).

## Expected Result

Wire constants confined to per-platform modules; trait model shared;
single conversion point into `InboundMessage`.

## Result

- QQ opcode/intent constants are module-local to `qq/gateway.rs:22-45`;
  gateway events are converted to `InboundMessage` at
  `qq/gateway.rs:271-278` (direct) and `:307-315` (group) — the conversion
  is thin field mapping with defaults for missing fields.
- Feishu protobuf frame types are module-local to `feishu/proto.rs`;
  events converted at `long_poll.rs:576-577` and `webhook.rs:198-199`.
- `InboundMessage`/`OutboundMessage`/`MessageHandler` have a single
  definition (`types.rs:74,125,175`) reused by framework adapters
  (`AgentChannelHandler`, `SessionHandler`, `QqMessageHandler`,
  `FeishuMessageHandler`) and by EKO (`AppChannelMessageHandler`).
- `dispatch_stream_to_send_tx`/`reply_with_empty_guard`
  (`channels/mod.rs:19-58`) centralize the streaming-chunk delivery
  contract shared by both platforms (dedup of final chunk).
- No worker naming; `subagent` appears only in an EKO comment
  (cli/channels.rs:200), not as a type.
- Minor: `QqMessageHandler`/`FeishuMessageHandler` wrapper duplication is
  an adapter concern, not a protocol-leak (kept because send semantics
  differ per platform).

## Deviations

None.

## Conclusion

Supports: compliant external-fixed-protocol isolation with a single typed
internal message model and lossless thin conversion.
