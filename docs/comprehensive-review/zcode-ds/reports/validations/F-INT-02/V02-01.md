## Claim

The LSP stack is registered and live-reachable in EKO: tools registered on
the primary agent at boot, servers started from discovered/merged config,
and plugin reload drives `LspManager::shutdown_all`.

## Method

1. `grep -rn "register_lsp_tools|start_server|restart_server|shutdown_all"`
   in echo-agent and echo-agent-cli.
2. Read `echo-agent-cli/echo-agent-app-core/src/runtime.rs:499-597`
   (`register_lsp_tools`), `:274` (call site in boot), and
   `plugin_runtime.rs:583,596,639,691,707,721,975` (shutdown_all callers).
3. Read `echo-agent/src/tools/lsp.rs` (tool registration `:493-502`,
   `open_file_for_lsp` `:458-476`).
4. `grep -rn "LspError::Timeout"` and `grep -rn "restart_count|max_restarts"`.

## Expected Result

Live path: EKO boot → `LspConfig::discover` + global/project `.lsp.yaml`
merge → `LspManager.start_server` per language → five LSP tools registered
→ agent invokes `lsp_diagnostics` etc. → `StdioLspClient` JSON-RPC over
stdio. `restart_server` unreachable from production; `max_restarts` unread.

## Result

- EKO boot (`runtime.rs:274`) calls `register_lsp_tools` unconditionally
  (app-core default features include `lsp`).
- Tools: `lsp_diagnostics`, `lsp_goto_definition`, `lsp_find_references`,
  `lsp_hover`, `lsp_status` (`tools/lsp.rs:493-502`; EKO registers each via
  `add_tool` at runtime.rs:578-584). Start failure at boot is warn-only
  (runtime.rs:563-566) — servers are best-effort.
- `LspManager::restart_server` (`manager.rs:105-108`) has zero production
  callers (only self-reference and tests). `max_restarts` is set
  (config.rs:59, types.rs:143-144, example demo55) but never read.
  `restart_count` is initialized and reported (client.rs:40,60,528) but
  never incremented.
- `LspError::Timeout` (`echo-core/src/lsp/client.rs:15`) has zero
  construction sites.
- Plugin reload paths await `shutdown_all()`/`stop_server` on real
  managers (plugin_runtime.rs:583-975).

## Deviations

None beyond the dead restart contract (recorded as finding
F-INT-02-P2-01).

## Conclusion

Supports: LSP is live in EKO (tools registered, servers auto-started,
shutdown reachable on plugin reload); the restart/timeout contract is
defined but not exercised.
