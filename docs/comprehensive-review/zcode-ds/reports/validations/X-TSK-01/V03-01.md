## Claim

The forbidden parallel CRUD surface (`todo_write`, `plan_create`,
`plan_patch`, `plan_execute`) has zero production definitions or registrations
in either repository — the only task-relation API is the revisioned
`task_create`/`task_update`/`task_list` family plus EKO's run-level
`task_execute` and Auto-mode launchers.


Every match classified as violation / test-only / conversion-helper / doc
reference / false positive.

## Expected Result

- `todo_write`: zero definitions; the only match is a positive assertion
  (a test that asserts the tool is NOT registered).
- `plan_create`/`plan_patch`/`plan_execute`: zero tool definitions; remaining
  `plan_*`-prefixed identifiers are the canonical framework patch types
  (`TaskPlanPatch`, `TaskPlanPatchOp`) and the `to_task_plan_patch` conversion
  helper.
- Registered task tool names: exactly `task_create`/`task_update`/`task_list`
  (framework) + `task_execute`/`create_complex_task`/`check_run_status`/
  `cancel_run` (EKO).
