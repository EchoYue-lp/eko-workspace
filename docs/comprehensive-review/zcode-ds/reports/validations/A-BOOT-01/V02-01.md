service is registered on the primary agent and/or pool exactly once per
process, with per-entry construction sets traceable from `main` to service.

## Expected Result

Each of the five surfaces (TUI, CLI, channels-only, channels+CLI, GUI)
reaches `bootstrap` exactly once and registers task tools / pool / watcher
once; services that exist in any surface exist in all (parity invariant).

## Result

- Exit code: not-applicable (static trace)
- Summary:
  - `bootstrap` reached exactly once per process on every surface (TUI/CLI/
    channels via main.rs:168; GUI via desktop.rs:160; the two bins never run
    together — main.rs:75-76 routes the package bin to desktop only in a
    gui-only build).
  - Config watcher: all surfaces (spawned before mode dispatch in main.rs, and
    in desktop.rs).
  - Task tools + pool binding: TUI/CLI/channels via main.rs:177/192; GUI via
    desktop.rs:201/217. Exactly once per process.
  - BackgroundTaskService + SchedulerRunner: GUI (desktop.rs:231-232) and
    TUI/CLI (start_headless_services via main.rs:258 or modes.rs:83). NOT
    started in channels-only mode (`--channels` without `--cli`,
    main.rs:391-403 calls only `run_channels_mode`, which builds no services).
  - MCP health monitor: GUI only (desktop.rs:243) — matches B-PATH-01-P2-01.
  - Dreaming: TUI (tui/mod.rs:1997-2006), GUI (desktop.rs:246-253), CLI
    (repl.rs:104-114); channels: none.
  - Session-end memory review (`on_session_end`): TUI (main.rs:306-327), CLI
    (repl.rs:454); GUI: no production caller anywhere under src/tauri or the
    desktop path.
  - Dead/unreachable composition APIs: `AgentRuntime::into_app_state`
    (runtime.rs:374-390) — zero callers; `TerminalManager::close_all`
    (src/tauri/terminal.rs:256) — zero callers outside the manager.
  - In the headless path, `start_headless_services` constructs a full
    `AppState` (modes.rs:57) purely to borrow `start_task_service` /
    `start_scheduler_with_store`; that AppState's own TaskRuntimeStore
    (state.rs:548) and WebhookEmitter (state.rs:469) are replaced at
    modes.rs:58/60 and discarded.
