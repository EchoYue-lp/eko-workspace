- Summary:

(a) F-LLM-01-P1-01 does NOT cover Anthropic: `stream_post`/`parse_sse_chunk`
are used by `OpenAiClient`/`DefaultLlmClient`/`AdapterClient` (client.rs);
`AnthropicClient::chat_stream` implements its own inline SSE loop
(anthropic.rs:478-624). Same defect class exists there, worse: malformed
events are dropped by `if let Ok(event) = serde_json::from_str(...)`
(anthropic.rs:510) with **no `warn!` log at all** (the shared transport at
least logs). F-LLM-03-P1-02 (message_delta usage shape) is a live instance
of this defect class firing on well-formed Anthropic payloads.

(b) `cache_hints` consumers: only `anthropic.rs:171-202` consumes them
(confirmed F-LLM-02-P2-01's claim). The main path sends
`Some(CacheHints{breakpoints: vec![], ..})` (think.rs:323-327,
react_loop.rs:50-53) and the adapter correctly falls back to
`AnthropicCachePlan::from_layout` (anthropic.rs:197-201), so cache
breakpoints ARE placed on the main path (test
`cache_hints_with_empty_breakpoints_still_places_cache_control` green).
The non-empty-breakpoints hint path is latent (no producer today).

(c) F-LLM-01 V03 assumption "Anthropic usage mapping feeds ChatChunk.usage":
**refuted on the real wire** — see V03-01/F-LLM-03-P1-02. This is a direct
correction to the F-LLM-01 handoff item "F-LLM-03 should confirm Anthropic
usage mapping feeds ChatChunk.usage (V03 depends on it)". The mapping code
exists (:584-617) but is unreachable because `message_delta.usage` cannot
deserialize.

(d) F-LLM-01-P3-01 (cancellation = silent end, no typed signal): confirmed
identical in the Anthropic adapter — `if ct.is_cancelled() { info!; return; }`
(anthropic.rs:482-486) ends the stream with no terminal chunk/error, same as
the shared transport. No new finding; the P3-01 fix should cover both paths.

New cross-checks from this comparison:
- F-LLM-01-P2-02 (usage observability path-dependent): the Anthropic adapter
  additionally breaks usage on the STREAMING main path (P1-02), which is
  worse than the OpenAI adapter (delivers usage in both modes per
  F-LLM-02 V02).
- F-LLM-02-P2-01's "cache_hints silently ignored on OpenAI" is confirmed
  provider-asymmetric by design; the Anthropic side consumes them.
