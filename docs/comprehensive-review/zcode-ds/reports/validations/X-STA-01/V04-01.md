## Deviations

The claim fails on four rows: GUI and TUI conversation deletion both leave the
full runtime checkpoint (new finding X-STA-01-P1-01) and TaskRuntime run data;
TUI additionally omits tool-execution cleanup (A-STATE-01-P3-02); uploads are
never cleaned (A-INP-01-P3-01). Workspace deletion is the only complete
cascade.

## Conclusion

The deletion cascade is complete only at the workspace granularity. At the
conversation granularity the most complete copy of the conversation — the
runtime checkpoint holding the full unfiltered message list (including tool
hand-offs and injected instructions), the plan, and active skills — survives
deletion on disk with no API or call site to remove it; a reused conversation
id would resurrect that context at the next Execute-mode turn
(`restore_thread_context`, echo-agent/src/agent/react/run/context.rs:502/571).
This supports finding X-STA-01-P1-01 and confirms the A-STATE-01/A-INP-01
canonical rows.
