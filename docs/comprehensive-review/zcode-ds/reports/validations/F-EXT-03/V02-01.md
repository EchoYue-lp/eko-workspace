## Claim

Registration and runtime reachability: every F-EXT-03 scope tool is registered
under its declared feature gate, the CLI enables those features, and the
read-only tool surface (`register_readonly_tools`) is the builder path for
EKO read-only Subagents.

## Method

Static tracing (no source modification):

1. Read `echo-agent/echo-tools/src/registry.rs` (registration lists per
   feature) and `echo-tools/src/lib.rs` (module feature gates).
2. Read `echo-agent-cli/echo-agent-app-core/Cargo.toml` (echo-agent features
   enabled by EKO).
3. Trace the registration entry points:
   - `echo-agent/src/agent/react/mod.rs:741-747` (`register_feature_gated_tools`
     dispatches to `register_all_tools` / `register_readonly_tools` on
     `AgentConfig.readonly_tools`).
   - `echo-agent-cli/echo-agent-app-core/src/infra.rs:639-640,772-773`
     (`build_readonly_subagent_agent` call sites) and `:615` (comment: readonly
     subset is "physical no-write enforcement").
   - `echo-agent-cli/echo-agent-app-core/src/plugin_components.rs:530`
     (`.readonly_tools()` builder use).
4. Enumerate, per scope tool family, the feature gate and whether the tool is
   registered in `register_all_tools`, `register_readonly_tools`, or both.

## Expected Result

- Every scope tool is registered under exactly the feature that gates its
  module.
- The CLI enables features: `data, statistics, chart, research, media, rag,
  web, database` (plus shell/files/git).
- `register_readonly_tools` registers only tools whose
  `Tool::permissions()` is read-only.

## Result

- Exit code: 0 (grep/sed reads; no commands executed beyond inspection)
- Summary:
  - CLI-enabled features (`echo-agent-cli/echo-agent-app-core/Cargo.toml:10-14`):
    `mcp, lsp, human-loop, subagent, git, tasks, shell, files, web, data,
    statistics, chart, research, media, rag` — `database` is NOT enabled by
    the app-core dependency list (sqlx tools are a framework option only).
  - Feature-gate → registration map (from `registry.rs`):
    | Feature | Tools registered (all / readonly) |
    |---|---|
    | `data` | 15 data tools + 3 data-quality tools / subset without `export_data` |
    | `statistics` | `exploratory_statistics` / same |
    | `chart` | `generate_chart` / same |
    | `web` | `web_fetch`, `web_search`, `web_extract` / same |
    | `media` | image/excel/pdf/word/text + `web_fetch_enhanced`, `image_fetch` / subset without `write_excel`, `export_text`, `WebFetchToolEnhanced`, `ImageFetchTool` (registered only in all) |

    | `research` | 8 tools / **all eight including `bibtex_generate` (permissions [Write]) and `research_remember` ([Read, Write])** |

    `registry.rs:18-19` and `infra.rs:615`.
