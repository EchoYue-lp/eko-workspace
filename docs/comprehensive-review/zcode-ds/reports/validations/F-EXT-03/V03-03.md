## Claim

`register_readonly_tools` (echo-tools/src/registry.rs) registers tools whose
`Tool::permissions()` declares `Write`, violating its documented invariant
("physically incapable of mutating state", registry.rs:18-19): specifically
`rag_index` (permissions `[Read, Write]`) and `bibtex_generate`
(permissions `[Write]`), where `bibtex_generate` writes an arbitrary file path
via `tokio::fs::write` without any `SecurityConfig::validate_output_file`
check.

## Method

Static inspection (read-only):

1. Read `echo-tools/src/registry.rs` lines 55-62 (rag block) and 161-176
   (research block) of `register_readonly_tools`.
2. Read `echo-tools/src/rag.rs:205-316` (RagIndexTool: permissions at
   212-214, `global_vector_store().write().await.add_chunks` at 305-306,
   embedder/API-key requirement in description at 216-220).
3. Read `echo-tools/src/research/bibtex.rs:16-112` (permissions at 21-23;
   `tokio::fs::write(path, ...)` at 94-101 with no path validation; `path`
   comes straight from the `output_file` parameter).
4. Confirm the builder path that consumes the readonly subset:
   `echo-agent/src/agent/react/mod.rs:741-747`; EKO build sites
   `echo-agent-cli/echo-agent-app-core/src/infra.rs:639-640,772-773`;
   `plugin_components.rs:530`.

## Expected Result

Every tool in the readonly subset must be non-mutating (Read-only
permissions) and must not be able to write to the filesystem or mutate shared
state.

## Result

- Exit code: not applicable (static inspection; no commands executed)
- Summary:
  - `rag_index` IS registered in the readonly subset (registry.rs:58-60)
    despite `permissions() == [Read, Write]`; its execution mutates the
    process-global in-memory vector store and can trigger embedding API
    network calls using `EMBEDDING_API_KEY` (description, rag.rs:218).
  - `bibtex_generate` IS registered in the readonly subset (registry.rs:172)
    despite `permissions() == [Write]`; its execution writes `output_file`
    (any path, relative or absolute, no `validate_output_file`, no
    `SecurityConfig` use) — an unvalidated file write reachable from a
    read-only Subagent.
  - The registry comment for the rag block claims "all read-only"
    (registry.rs:55) and the top-of-function doc claims the subset makes
    read-only Subagents "physically incapable of mutating state"
    (registry.rs:17-19).
  - The readonly builder path is live: `AgentConfig.readonly_tools` →
    `register_feature_gated_tools` (`react/mod.rs:741-747`), set by
    `build_readonly_subagent_agent` (infra.rs:639-640, 772-773) and the
    plugin component builder (`plugin_components.rs:530`).
