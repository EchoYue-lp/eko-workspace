## Claim

Non-finite f64 values (NaN / ±Infinity) that result from overflow in the
statistics/data tools (e.g., `(x - mean).powi(2)` overflowing to inf, or
`inf/inf` → NaN) are serialized by `serde_json` as JSON `null` without an
error, so tool outputs silently replace computed-but-overflowed statistics
with `null`.

## Method

Standalone program compiled against the serde_json rlib already built in the
echo-agent target cache:

```text
cd /tmp/f-ext-03-v03
rustc --edition 2021 nan_test.rs \
  --extern serde_json=<target/debug/deps/libserde_json-*.rlib> \
  -L <target/debug/deps> -o nan_test && ./nan_test
```

The program exercises the same construction used by `DataStatsTool`
(`data.rs:692-703`), `statistics.rs:101-115`, and `any_value_to_json`
(`data.rs:2840-2845`): `json!({"mean": NaN, "std": inf})`, plus
`serde_json::to_value(NaN)` and `Number::from_f64(NaN)`.

## Expected Result

Either an error/panic on non-finite input (making the tool fail loudly) or an
explicit marker in the output; the tool must not silently produce `null` for
computed statistics.

## Result

- Exit code: 0
- Summary:
  - `json!({"mean": NaN, "std": inf})` → `{"mean":null,"std":null}` — silent
    null, no panic.
  - `serde_json::to_value(NaN)` → `Value::Null`.
  - `serde_json::Number::from_f64(NaN)` → `None`.
- Log/artifact: `/tmp/f-ext-03-v03/nan_test.rs`.

## Deviations

None. This confirms the silent-null behavior, i.e., the defect claim.

## Conclusion

Supports: f64 overflow in data/statistics tool arithmetic (e.g.,
`DataStatsTool` variance/mean for extreme values, `statistics.rs`
skewness/kurtosis moments, `CorrelateTool` correlation cells) is not reported
as an error and not marked — the JSON output contains `null` where a finite
statistic was expected, indistinguishable from a null input cell. Evidence for
F-EXT-03-P3-01. Note: `data.rs format_smart_float` (used by the ratio tool)
does handle NaN/Inf explicitly as strings, so handling is inconsistent across
the same module family. Does not prove that typical (non-overflow) inputs are
affected.
