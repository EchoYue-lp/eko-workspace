## Claim

Replaying the same user scenario through each surface's adapter yields the
same logical event flow (one shared driver, one terminal contract, same
identity propagation), with surface differences confined to sink/rendering —
and any deviation is a recorded parity finding (own or canonical).

## Method

Static event-flow replay. For each scenario, the turn was traced through the
surface adapter into the shared core and out through the sink, comparing:
(a) entry normalization, (b) driver invocation, (c) per-surface sink
projection, (d) terminal handling, (e) queue/steer/cancel behavior. Anchors
were re-verified at the reviewed commits where the scenario crosses a
surface adapter; deep driver/sink semantics are consumed from dependency
reports (A-CHAT-01, A-SRF-01..04, A-SRF-03).

Scenario set (the same five scenarios a Q-E2E-01 suite would run
dynamically):

1. **S1 — plain chat turn**: user sends a text message; agent streams,
   calls one safe tool, answers.
2. **S2 — cancel mid-turn**: user aborts the in-flight turn.
3. **S3 — queue a second message while a turn runs**.
4. **S4 — task run with subagent + tool calls** (Implementation task on a
   writer subagent).
5. **S5 — attachment**: user sends a file/paste with the message.

## Expected Result

S1 and S5 converge on the shared driver on all four interactive surfaces;
S2/S3/S4 show exactly the recorded surface asymmetries; no additional
asymmetry beyond the filed findings and the two new findings in V01.

## Deviations

- All replay steps are static traces; no live LLM/IM traffic was executed
  (read-only review). The exact interleaving of S3 on channels (concurrent
  turns on one agent) is unresolvable statically and recorded as residual.
- S2 on REPL ("Ctrl+C kills the process") follows from the verified absence
  of any signal handler on the CLI path plus default SIGINT disposition
  (A-SRF-04-P1-01 evidence); not dynamically reproduced.

## Conclusion

The replay supports: one shared driver with four equivalent entry
normalizations (S1, S5); terminal truthfulness only on the TUI (S1/S2);
queue policy exists on GUI/TUI but is defective on both (S3); task
projection and control are the most divergent capability (S4); storage
divergence follows the workspace gap (S5). No asymmetry beyond the filed
findings plus X-SRF-01-P2-01/P2-02/P3-01 was observed.
