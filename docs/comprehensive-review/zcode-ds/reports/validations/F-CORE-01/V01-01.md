  `:10`), deterministic `event_id` (SHA-256 of identity parts + sequence,

  (conversation/run/turn/execution/parent), timestamp, payload.
- `EventIdentity` (`:13-22`): conversation_id/run_id/turn_id/execution_id/

  `AgentInvocationContext.runtime` (ExternalRunContext) with fallbacks.
- `AgentEvent` (`mod.rs:138-310`): `#[serde(tag = "type", content = "data",
  rename_all = "snake_case")]` + `#[non_exhaustive]`; 18 variants incl.
  LlmUsage (cache observability, `:162-177`), BudgetDecision (`:179-190`),
  ToolCall/Result/Error/Stream, ToolBatchStart/End, SafetyNotice,
  ParameterError; terminals: FinalAnswer/Cancelled/Error (`is_terminal`
  `:331-336`); `is_checkpoint` (`:433-445`) defines persistable phase
  boundaries.
- `AgentPhase` (`:318-327`): Thinking/Acting/Terminal, `#[non_exhaustive]`,
  no serde derive (local-only mapping).
- `ReactError` (`error.rs:16-57`): `#[non_exhaustive]`, 11 variants, 2
  feature-gated (Mcp/Channel), all sub-errors Box-wrapped; `Result<T>` alias
  (`:415`); From impls for all subsystem errors incl. reqwest
  (`:396-412`, feature-gated).
- Sub-errors: LlmError (5), ToolError (9, incl. InvalidPath/AccessDenied/
  FileTooLarge/Timeout), ParseError (5), AgentError (12, incl. Cancelled/

  side_effect + retry_after_ms + idempotency_key + postcondition.
- `ExternalRunContext` (`tools/mod.rs:964-976`): conversation/run/turn/
  execution/isolation identity.
- `AgentInvocationContext` (`mod.rs:63-84`): runtime + working_dir + cancel
