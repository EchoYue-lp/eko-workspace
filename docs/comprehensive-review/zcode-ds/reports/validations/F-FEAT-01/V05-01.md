## Claim

(1) The `default` feature sets and the `full` meta-feature match their documentation; (2) feature-implied dependencies (`statistics → data`, `subagent → tasks`) are correctly declared in manifests; (3) the docs.rs metadata feature list matches the declared feature set except the documented `data` exclusion.

## Method

1. Compare each manifest's `default = [...]` against the claim "zero default features" (README) and against the root gate `cargo check --workspace --lib --no-default-features --locked` (AGENTS.md).
2. Diff `full` (root `echo-agent/Cargo.toml:67`, echo_tools `echo-tools/Cargo.toml:17`) against the full declared feature set.
3. Verify implied edges: `statistics = ["data"]` (echo-tools), `subagent = ["tasks"]` (root) — declared? needed?

5. Compare README feature table (`README.md:113-147`) against the manifest.

- Root default = [] and echo_execution default = ["files","shell"] identified; `full` omits exactly 7 markers; docs.rs omits `data` (documented) plus an undocumented remainder; README table matches the manifest.
